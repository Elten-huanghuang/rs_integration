【RS Integration 1.3.0 更新公告】

适用版本：Minecraft 1.20.1
更新范围：1.2.9 -> 1.3.0

一、新增功能

1. 新增铁砧材料记忆与补货功能。
   - 自动记录每名玩家最近使用的 6 种铁砧材料。
   - 点击记忆栏即可从玩家背包和 RS 网络补充材料。
   - 支持一键交换铁砧的主物品槽与材料槽。
   - 材料不足时会显示缺少数量，并可自动加入 JEI 收藏。
   - 默认支持原版铁砧、Goety 黑暗铁砧和 Iron's Spells 'n Spellbooks 奥术铁砧。
   - 增加 Inventory Profiles Next 快速重命名兼容，可在其恢复背包后继续从 RS 补齐材料。

2. 合成计划新增“最大”按钮。
   - 可根据当前库存、配方和绑定机器异步计算最大可合成次数。
   - 合成次数上限由原来的 64 提升至 1024，服务器仍可通过配置调整。
   - 新增 +64 快捷调整，并完善数字输入、滚轮调整和服务端边界校验。

3. 合成计划会记住上次选择的产物去向，重新打开界面后无需重复选择。

二、合成规划与执行优化

4. 修复机器单个输入槽的标签材料规划。
   - 同一个机器槽位现在只会选择一种具体材料，避免不同颜色、不同变体混入同一槽位导致机器卡住。
   - 不同机器槽位仍可分别使用不同的同类材料，例如工作台的多个木板槽位仍可混用。

5. 修复无 NBT 配方材料被错误按“无 NBT 物品”严格预留的问题。
   - 带耐久、词条或其他状态数据的同类物品，现在可正确用于不要求 NBT 的配方。
   - 明确要求 NBT 的配方仍会保持严格匹配。

6. 修复 Lychee 批量合成跨 NBT 变体时的材料预留问题。
   - 不要求 NBT 的 Lychee 配方可合并使用不同 NBT 变体。
   - 要求精确 NBT 的配方不会错误混用材料。
   - 增加图执行重试诊断，便于定位材料竞争或预留失败。

7. 修复多台烹饪锅并行批处理时，图材料与额外材料没有按每次操作正确组合的问题。

8. 合成执行会复用刚刚预览并通过验证的计划。
   - 开始合成前仍会重新校验库存、RS 网络、机器绑定和配方版本。
   - 状态未变化时直接使用已验证计划，减少重复规划，并保证预览与实际执行一致。

9. 加固递归合成逻辑。
   - 修复会消耗自身产物的增殖配方被错误合并、错误计算种子数量的问题。
   - 修复递归制作中已生产材料、初始库存和机器步骤之间的衔接问题。
   - 配方图预热对原版工作台配方使用稳定投影，降低第三方反射数据异常的影响。

10. 完善机器配方材料的分类与预留。
   - 将配方图中的主要材料与机器运行所需的额外材料分开处理。
   - 燃料、催化物、祭坛能量材料等会按实际操作次数或机器工作单元正确预留，避免批量与并行合成重复扣除或数量不足。

11. 修复绑定机器存在多个可用配方分支时，执行阶段丢失其他候选配方的问题；首选配方不可用时可继续尝试其他有效分支。

12. 加强无效计划保护：计划不成立且未重新选择有效分支时，确认按钮不会启动合成。

三、模组兼容修复

13. 改进原版锻造台递归合成。
   - 必须绑定对应锻造台后才能执行。
   - 会从实际库存中选择可用的基础装备，并保留其耐久、附魔和其他 NBT 数据。
   - 预览结果与实际锻造结果保持一致。

14. 改进 TACZ 及兼容枪包工作台识别。
   - 根据工作台方块 ID 和完整配方 ID 校验兼容性。
   - 避免把配方发送到不支持该配方的枪械工作台。

15. 加固 Goety 仪式自动合成。
   - 在提取材料前检查研究、献祭、结构、经验等级和附魔目标等前置条件。
   - 不支持的献祭仪式、未完成研究、结构错误或无法可靠验证的仪式会直接阻止执行，避免先扣材料后失败。
   - 合成计划界面会提前显示对应警告或阻止原因。
   - 兼容不同 Goety API 参数类型及献祭名称返回格式。

16. 修复 Apotheosis 附魔图书馆导入面板与 JEI 界面重叠的问题。

17. 收紧祭坛和机器绑定匹配规则。
   - 脚本生成目录、市场、PMMO 合成目录及非执行型 Goety 组件不会再被误认为可执行机器类型。
   - 机器选择会同时校验配方 ID 与绑定机器能力。

18. 修复 Enigmatic Addons 人造石英花放入共振盘后无法免疫其指定 Debuff 的问题。
   - 共振盘中的全部人造石英花会加入原模组的免疫判定，不受石英花数量上限影响。
   - 具体免疫效果仍完全使用 Enigmatic Addons 原生 NBT 与事件规则。

19. 修复共振盘内部物品被 RS 普通库存和合成规划读取的问题。
   - 共振盘槽位现在只对明确支持的被动效果、专用兼容与 Lychee 催化剂开放，不再作为普通 RS 材料显示或使用。
   - 修复取出希腊火桶等 Lychee 催化剂后仍残留在磁盘列表中的幽灵显示。
   - 催化剂取出后会立即同步状态，服务端执行配方时也会按共振盘当前内容重新校验，不再继续使用已取出的催化剂功能。

四、权限、区块与稳定性

20. 所有候选机器在执行前都会检查 FTB Chunks 和 Cadmus 领地权限；无权限的机器不会参与分配。

21. 远程 GUI 和自动合成不再主动加载未加载区块。
   - 未加载的机器会被跳过，并优先尝试其他已加载机器。
   - 只对已经加载且正在使用的区块保留临时票据，减少意外强制加载和区块票据泄漏。

22. 调整领地保护兼容策略。
   - 保护模组明确返回其他所有者时拒绝操作。
   - 保护 API 变化或查询失败时记录限频警告，避免错误地把机器所有者锁在自己的机器之外。

23. 加强服务端数据包、重复次数、异步请求和计划缓存校验，避免过期请求、越界数值或失效计划被执行。

五、界面与说明

24. 补充并整理中英文说明，详细说明 JEI 配方入口、HUD、村民交易补货、Apotheosis 图书馆、特殊自动化及各模组支持范围。

25. 新增铁砧记忆相关图标、提示文本和配置项，并同步更新网络协议。

26. 调整共振存储磁盘配方：核心材料由 RS 4k 存储部件提升为 64k 存储部件。

27. 版本号由 1.2.9 更新为 1.3.0。

更新前请备份世界与配置文件。客户端与服务端请使用相同版本。
