<h1 align="center">RS Integration</h1>

<p align="center">
  <a href="README.md">English</a> | <strong>简体中文</strong>
</p>

RS Integration 让 Refined Storage 可以自动使用其他模组的机器。你只需在 JEI 中选择想做的物品，它就会检查材料、处理前置配方、调用已绑定的机器，并把成品送回 RS 网络。

**当前版本：1.4.1 | Minecraft 1.20.1**

[1.4.1 更新公告](docs/RELEASE_NOTES_1.4.1.md) | [MC 百科完整介绍](https://www.mcmod.cn/class/29199.html)

## 运行要求

| 依赖 | 要求 |
|---|---|
| Minecraft | 1.20.1 |
| Forge | 47+ |
| Refined Storage | 1.12+，必需 |
| JEI | 客户端必需，用于配方操作和合成计划预览 |
| 其他集成模组 | 可选；只有检测到目标模组时才加载对应模块 |



## 主要功能

### 递归远程合成

**即使没有 RS 无线终端，也可以从玩家背包执行普通配方递归合成。**

- 在 JEI 中点击 RSI 按钮，即可预览并开始合成。
- 自动处理工作台、模组机器、交易和多方块结构需要的前置材料。
- 合成前会显示完整步骤、缺少的材料和可替换配方。
- 按当前背包与 RS 库存快照提前选择一个规划器，特殊前置配方不会再先后重复规划。
- 卡片、树状图和总需求统一区分消耗材料、返还容器与可复用催化剂；缺少材料的名称可以单独加入 JEI 收藏。
- 会剪除同颜色或同族材料之间没有净收益的递归转换，同时保留精确产物和数量确有增长的配方。
- 没有先后关系的步骤可以同时进行，多台同类机器也会自动分配工作。
- 大型原版批量合成会跨 tick 分片，并在多名玩家和多条合成链之间公平共享全服执行预算。
- 合成失败或取消时会尽量退回材料，避免吞物或重复产物。
- 机器的单个输入槽只会选择一种材料，避免炽炉等机器混搭不同材料后卡住；工作台的不同格子仍可混用不同木板等同类材料。
- 按 `P` 查看进度，也可以在进度界面或使用 `/rsi cancel` 取消合成。

### 机器绑定与远程访问

- 手持网络连接器潜行右键机器进行绑定或解绑。
- 按 `;` 可绑定附近已加载区块中的受支持机器。扫描会跨 tick 分片，跳过重复绑定，并可使用手中、玩家物品栏或饰品栏里的网络连接器，分别统计领地保护和无效结构。
- 绑定记录包含维度和坐标；方块被破坏后会清理失效记录。
- 从 RS 界面远程打开兼容机器 GUI，关闭后可返回终端。
- 机器管理中心支持搜索、状态查看、收取产物、打开 GUI 和数字键选择。
- 在机器管理中心按 `Ctrl` + 左键可以立即取消机器绑定，列表会同步刷新，不需要再绑定一台机器或重新进入世界。
- 可以按玩家收藏常用机器，使其在机器管理中心和侧边栏中保持易于访问。
- 机器标签支持把手持物品直接放入输入槽，潜行操作时也可补充燃料。
- 多台同类机器可以自动分担重复的合成任务。
- 远程操作会检查 FTB Chunks 和 Cadmus 的领地权限，且不会强制加载未加载的目标区块。

### JEI 与 RS 界面工具

- 在 JEI 物品列表拖框批量收藏或隐藏。
- Alt 点击物品按模组筛选；Alt 中键清空搜索。
- `Ctrl+T` 将当前 JEI 配方传送到 RS 合成终端。
- 按住 `Ctrl` 在 RS 格子上左键拖动，每个经过的格子提取一个物品。
- 可拖动侧边栏可在其他界面显示 RS 库存和机器标签，并支持拼音搜索。
- RS 网格支持渐进式 `#` tooltip、`$` 标签和 `@` 模组搜索；JEI 就绪后即开始预热，搜索过程不会阻塞渲染，并会尽量复用磁盘缓存。
- 搜索框会按搜索模式保存有界的本地历史记录，可从历史浮层恢复、收藏、取消收藏、单条删除或全部清空。
- Sol Carrot 的“尝过/未尝过”是当前玩家的动态状态，在 RS 和 JEI 中不会写入共享搜索文本。
- 配方卡片、树状图、总需求和“无法获取”文字中的缺少材料，都可以单独或批量加入 JEI 收藏。

### JEI 注册与配方入口

- RSI 作为 JEI 插件注册，并在受支持的原版及模组配方页添加 RSI 合成按钮；点击后会检查绑定机器、生成递归材料计划并打开预览。对支持远程 GUI 的已绑定机器，还会同时注册直接打开机器界面的按钮。
- 注册三个专用 JEI 配方分类：FTB Quests 任务物品提交、Distant Worlds Lithum 祭坛和 Project MMO 概率回收。FTB 任务条目会在任务数据同步后按玩家动态加入。
- Lithum 核心和 PMMO 回收方块会注册为各自分类的配方催化剂；PMMO 后同步的回收数据也会动态补进 JEI。
- 注册通用 RS 配方转移处理器，并为 Eidolon 工作台注册 13 个配方槽的专用转移处理器。所有分类、催化剂和入口都只在对应模组已安装且集成功能启用时加载。

### HUD 与世界内提示

- **天华砧 / 锻造工具站 HUD**：准星指向机器时显示槽内物品、当前/所需锤击数、锻造炉温度、配方温区、余烬储量与单锤消耗、失误次数和无配方警告。工具站还会显示目标温度与温变率；HUD 底部同时显示温控范围、拉杆绑定、自动补货和自动锤炼状态。
- **Distant Worlds Lithum 祭坛 HUD**：准星指向 Lithum 核心时显示祭坛空闲/工作状态、当前配方或产物、能量/上限、恢复速度，以及周围八个基座的物品与数量。该 HUD 可通过客户端配置 `distantWorlds.enableHud` 关闭。
- **合成进度 HUD**：执行异步合成时在屏幕右侧显示目标物品、总体百分比、完成/运行节点、当前步骤及机器状态；可在按 `P` 打开的进度界面中单独隐藏或恢复。
- **绑定提示 HUD**：手持可绑定的网络连接器并指向支持的机器或祭坛时，会在快捷栏上方提示当前操作是绑定还是解绑。

### 自动进食

打开 RS 合成网格后，可以直接使用网络里存放的食物：

- **多样饮食**：配合 SolCarrot，自动吃掉还没有记录过的食物。
- **堆叠暴食**：选择一种食物，自动吃到饱或达到单次上限。
- 堆叠暴食会识别“暴食的赞赏”等允许满饱食继续进食的效果。
- **膳食均衡**：配合 Diet，自动选择食物补充较低的营养组。
- 可以设置食物黑名单和状态效果黑名单，避免误吃不想使用的食物。
- 吃完后的碗、瓶子等容器会优先放回 RS 网络。
- 服务器可以设置使用条件、每次消耗的物品和单次进食上限。

### 村民交易补货

- 在村民交易界面选中一项交易后按 `Space`，自动补充两个付款槽，便于连续交易。
- 优先使用玩家背包中的匹配物品，再从当前可访问的 RS 网络提取剩余数量。
- 每个付款槽会补到其有效堆叠上限，而不只是补足一次交易所需的数量。
- 界面会显示来自背包和 RS 的补充数量，并明确提示部分补货、无网络、无提取权限或交易失效。
- 缺少的付款物品及数量会显示在交易界面，并自动加入 JEI 收藏。

### 神化附魔图书馆

- 先把 Apotheosis 图书馆或末影图书馆绑定到 RS，打开图书馆界面后即可使用 RSI 附魔书导入面板。
- 扫描绑定 RS 网络中的全部附魔书，并按包含 NBT 的完整物品身份合并显示库存数量。
- 可以搜索附魔或附魔书信息、选择当前筛选结果，并导入筛选结果或全部兼容附魔书。
- 导入前会明确标记无效附魔书、不支持的自定义数据，以及被目标图书馆拒绝的附魔书。
- 扫描与导入均由服务端校验；未成功提交的附魔书会退回 RS，RS 无法接收时也会安全返还。
- 神化图书馆原生筛选框同时支持拼音和注册名搜索。

### 补货与物品管理

- **重铸台补货**：在 Apotheosis 或 Ancient Reforging 重铸界面按空格，自动从 RS 网络补充符石；缺少时会加入 JEI 收藏。
- **远程侧边栏**：按 `Y` 在其他界面查看和搜索 RS 库存，也可直接查看物品用途与配方。

### 特殊自动化兼容

- **余烬自动猜炼金**：绑定 Embers Rekindled 炼金台后，可以自动摆放材料、点火并根据黑钉/白钉反馈反复试错，逐步排除候选炼金编码；成功后会保存结果，后续同配方直接复用。也可启用计算模式，使用确定性布局跳过试错。
- **天华砧自动敲**：手持工匠锤并在天华砧设置中开启自动锤炼后，会按照砧的锤击冷却自动敲击；设置界面还支持温度上下限、锻造炉拉杆控温和自动补充锻造材料。
- **次元磁铁吸取突变生物残骸**：Distant Worlds 产生的凋灵图腾和充能凋灵图腾（`wither_totem` / `charged_wither_totem`）会转为磁铁可处理的掉落实体，由已绑定的次元磁铁直接送入 RS 网络，不会先塞进玩家背包。
- **Goety 仪式安全确认**：召唤、献祭和转化请求只会准备基座材料，并把激活物交给玩家，不会自动启动仪式；玩家可以先确认目标和环境，避免误召唤或吞材料。
- **茶壶和蒸笼结构**：Farmer's Respite 茶壶自动化遵守原生容器与流体语义；Youkai's Homecoming 同时支持完整多层蒸笼和有效的一层蒸笼加盖子结构。
- **妖怪发酵罐流体配方**：Youkai's Homecoming 与 Gensokyo Delight 的纯液体、固液混合发酵均会把装液容器列入递归材料；成品与空容器会正确回收，并保留旧版水配方兼容。

### 神化刷怪笼升级

- 手持有效的 RS 网络物品，潜行右键 Apotheosis 刷怪笼即可打开升级界面；手持 BD 终端时使用 `Alt + 右键`。
- 界面会列出当前可用的正向升级、完成状态、所需材料和 RS 库存数量。
- 可以同时选择多个升级，并在确认前预览完整的材料依赖与合成计划。
- 已有材料会从所连接的 RS 网络扣除；缺少材料且存在有效配方图时，会自动递归制作。
- 扫描和执行均由服务端校验玩家、网络、维度、距离、刷怪笼状态和已预览的选择。

### 容器一键转移

- 打开箱子、机器输入界面等容器后按 `F`，即可把容器中的物品全部转移出去。
- 按 `G` 可以切换转移目标：发送到已绑定的 RS 网络，或发送到精妙背包。
- 转移过程中会遵守过滤器、物品黑名单和目标容量；无法转移的物品会留在原容器中。
- 在聊天框、搜索框等文字输入界面中不会误触发转移。
- 在玩家物品栏和合成访问器等需要原版副手切换的界面中也会禁用 `F` 转移，让按键恢复原版行为。

### RS 侧边栏与机器管理

- 按 `Y` 随时打开或收起侧边栏，不需要离开当前界面。
- 侧边栏可以查看 RS 网络中的物品数量，并显示已经绑定的机器。
- 支持按名称、拼音、数字和物品 ID 搜索，适合在大型整合包中快速找物品。
- 鼠标悬停物品后按 `U` 查看用途，按 `R` 查看配方，结果会直接打开 JEI。
- 点击机器标签可以远程打开机器界面；机器被破坏或失效后会自动从列表中清理。
- 按 `H` 打开机器管理中心，可搜索机器、查看状态、收取产物、打开 GUI，并用数字键快速选择机器。
- 网络中安装共振磁盘后，可以从机器管理中心直接打开其共振背包。

### 鼠标拖动与快捷操作

- 在 RS 合成网格中按住 `Ctrl` 并拖过多个格子，可一次从 RS 网络各取出一个物品。
- 在侧边栏中按住鼠标左键拖过多个物品，可把它们平均分配到已绑定的机器；单击则可取出整组，右键取出一个。
- JEI 物品列表支持拖框批量收藏、隐藏或清除选择，也可以按模组快速筛选。
- 合成计划中的节点支持右键折叠/展开，右键拖动平移，`Ctrl` + 滚轮缩放，滚轮调整合成数量。

### 共振磁盘

共振磁盘是一种特殊 RS 存储磁盘，盘内物品可以像玩家随身携带一样参与效果与资源查找。

- 支持属性、`inventoryTick`、事件驱动被动效果和兼容资源查询。
- 对配置为可变的物品保存 NBT/耐久变化，而不是只模拟一次副本。
- 默认支持 Apotheosis 药水护符、Muyimeng 混合药水护符、Reliquary 烈焰术士法杖、Enigmatic Addons 石英花、Forbidden & Arcanus 幽灵之眼护符。
- 支持勇三/月之石九剑书、Wizard Terra Curios 的 `BuffItem`、Terra Equipment 成组无限药水。
- 支持存放细雪桶、原液，毒液等的存放，存放后支持递归合成
- 支持将盘丢入井中，或者人跳入井中（需将盘放进RS，携带终端）获得虚空恩惠的能力，可解锁malum转化的能力
- 阻止共振磁盘被 RS 磁盘的 `Shift` + 右键快捷操作误拆成 4K 存储原件和元件外壳。
- 同一个 RS 网络只能启用一张共振磁盘，避免被动效果和资源重复计算。

### 精妙背包改造

- 提供四种 RS 专用精妙背包升级：
- **次元磁铁**：把范围内符合过滤条件的物品直接送入 RS 网络。
- **次元拾取**：接管拾取升级，从 RS 网络或背包规则处理掉落物。
- **次元喂食**：从 RS 网络取食物自动喂食玩家。
- **次元补货**：背包需要物品时从 RS 网络自动补充。
- 次元磁铁可以吸取地面掉落物，并在满足过滤条件时直接送入绑定的 RS 网络，不再占用背包空间；磁铁范围和过滤槽数量可配置。
- 次元拾取可以把拾取到的掉落物直接存入 RS，仍可使用精妙背包的过滤规则。
- 次元喂食和次元补货会优先从 RS 网络取物，过滤器可以限制食物或补货物品的种类。
- 这些升级都可以潜行右键 RS 控制器绑定网络；升级界面可以启用/禁用升级并配置过滤物品。
- **压缩升级增强**：安装 Majrusz's Accessories 后，精妙背包的压缩升级可以按过滤规则自动压制饰品，逐步合并不同品质，直到达到 100% 或无法继续合并。
- 支持将磁铁、拾取、喂食、补货等兼容升级重定向到 RS 网络。
- 精妙背包的存入升级可以直接把物品送进 RS 网络。
- 压缩升级可以自动合并符合条件的 Majrusz's Accessories 饰品。

### FTB 任务物品检测

- 检测由 RS 合成、容器转移、磁铁、拾取和其他外部物品移动带来的物品数量变化。
- 物品实际进入 RS 网络后，会同步到 FTB Quests 的物品任务进度；模拟插入、销毁、退款和恢复物品不会计数。
- 递归合成中已确认产出的主产物也会同步任务进度，包括随后被下游配方消费的中间产物；容器返还和退款不会计数。
- 支持 FTB Quests 的物品匹配规则，包括物品过滤和 NBT 判定。
- 在 FTB 任务界面点击提交时，可以直接从 RS 网络扣除缺少的物品；缺少的物品会进入 JEI 收藏。
- 对递归制作出的物品和外部获得的物品分别记录，避免同一批物品重复计数。
- 需要同时安装 FTB Quests 和 FTB Teams；若整合包已有其他自动检测模组，RS Integration 会自动让出检测功能。

## 快速开始

1. 建造并供能一个 Refined Storage 网络。
2. 获取 RSI 网络连接器。
3. 潜行右键绑定单台机器，或按 `;` 扫描并绑定附近机器。
4. 在 JEI 打开配方并点击 RSI 合成操作。
5. 检查合成计划，选择替代配方或重复次数，然后启动。
6. 按 `P` 查看进度；完成后产物进入 RS，没有网络时进入玩家背包。

## 默认按键

所有按键都可以在 Minecraft 控制设置中修改；配置中的数字键码使用 GLFW 值。

| 按键 | 场景 | 功能 |
|---|---|---|
| `F` | 容器界面 | 将容器内容全部转移到当前目标 |
| `G` | 任意/容器界面 | 切换 RS / 精妙背包传输目标 |
| `Y` | 任意界面 | 显示/隐藏 RS 侧边栏 |
| `H` | 任意界面 | 显示/隐藏机器管理中心 |
| `P` | 任意界面 | 打开/关闭当前合成进度 |
| `;` | 世界中 | 使用手中、物品栏或饰品栏中的网络连接器绑定附近机器 |
| `Alt` + 左键 | JEI 物品 | 按模组筛选 |
| `Alt` + 中键 | JEI 物品列表 | 清空搜索 |
| `Ctrl+T` | JEI 配方 | 传送到 RS 合成终端 |
| `Ctrl` + 左键拖动 | RS 格子 | 每格提取一个物品 |

## 配置

配置文件本身包含注释和取值范围：

- `config/rs_integration/common.toml`：功能开关、可选模组集成、被动效果、自动进食、范围绑定距离与预算、侧边栏、GUI 机器列表。
- `saves/<世界>/serverconfig/rs_integration/server.toml`：配方选择、纯/typed 规划预算、预览准入队列、递归限制、催化剂偏好、变体转换保护、原版每 tick 预算、DAG 并发、保护库存和机器策略。
- `config/rs_integration/client.toml`：侧边栏布局、HUD 偏好，以及 RS 特殊搜索的预热、渐进刷新、索引、拼音线程和磁盘缓存设置。

重要服务端选项包括首选/黑名单配方、重复次数、解析预算、并发图节点/操作数量、按模组并行策略和全局合成超时。带版本的配置迁移会更新指定的旧默认值，同时保留用户自定义值；新增列表项仍需手动合并，或删除旧配置后重新生成。

## 诊断

- `/rsi cancel`：取消玩家当前合成链。
- `/rsi_debug`：向权限等级 2 的管理员提供合成链、账本、配方索引、处理器、绑定、解析追踪、审计、Embers 缓存/锁和性能诊断。
- `diagnosticVerboseLogging`：排查问题时启用详细解析与调度日志。
