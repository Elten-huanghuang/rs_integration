<h1 align="center">RS Integration</h1>

<p align="center">
  <a href="README.md">English</a> | <strong>简体中文</strong>
</p>

不必再手动把材料搬到不同机器之间：在 JEI 选择想做的物品，RSI 会查看现有材料、制作缺少的前置物品、操作已连接的机器，并把成品送回存储网络。

**当前版本：1.5.0.5 | Minecraft 1.20.1**

[1.5.0.5 更新公告](docs/RELEASE_NOTES_1.5.0.5.md) | [MC 百科完整介绍](https://www.mcmod.cn/class/29199.html)

## 运行要求

| 依赖 | 要求 |
|---|---|
| Minecraft | 1.20.1 |
| Forge | 47+ |
| Refined Storage | 1.12+，可选；未安装时仍可使用玩家背包递归合成等功能 |
| JEI | 客户端必需，用于配方操作和合成计划预览 |
| 其他集成模组 | 可选；只有检测到目标模组时才加载对应模块 |



## 主要功能

简单来说：选好目标，先检查计划，再决定是否开始。RSI 可以使用背包和网络中的材料，调用支持的机器，并在开始前告诉你还缺什么。

### 递归远程合成

**即使没有 RS 无线终端，也可以从玩家背包执行普通配方递归合成。**

- RSI 会沿着配方链自动处理工作台、支持的模组机器、交易等前置步骤。
- 开始前先显示制作步骤、现有材料、缺少材料和可选配方；由你决定是否开始。
- 可以调用已连接的机器，也能让多台同类机器分担工作。部分普通配方不需要无线终端，直接使用背包材料即可。
- 支持时会返还容器和未用完的材料。按 `P` 查看进度，可在进度界面或输入 `/rsi cancel` 取消。

### 机器绑定与远程访问

- 手持网络连接器潜行右键或按 `Alt` + 右键绑定机器，也可以按 `;` 搜索并绑定附近机器；机器被拆除后会自动清理失效绑定。
- 在 RSI 界面远程打开机器、查看状态、收取产物或直接放入物品，不必来回跑动。
- 收藏常用机器；多台同类机器可以分担重复任务。
- 远程操作遵守 FTB Chunks/Cadmus 领地权限，也不会为了运行机器强行加载远处区块。

### JEI 与 RS 界面工具

- 可以收藏缺少的材料、按模组筛选 JEI、用 `Ctrl+T` 把配方传到 RS 网格，或在 JEI 物品上按鼠标中键从网络取出一组。
- 侧边栏可在其他界面搜索网络物品和查看机器；按住 `Ctrl` 拖过 RS 格子，每格取出一个物品。
- RS 搜索支持名称、模组（`@`）、标签（`$`）和提示文字（`#`）；最近搜索可以再次使用、收藏或删除。
- 在 RS 或 Beyond Dimensions 终端按 `F`，可把当前 JEI/EMI 选中的物品填入搜索框。

### Tetra 与 JEI 联动

- 使用 Tetra 加工台时，JEI 只显示适合当前部件的材料；按住 `Ctrl` 悬停可预览效果，也能按属性排序材料。

### JEI 注册与配方入口

- 支持的配方会出现 RSI 合成按钮；已连接的机器也可能提供直接打开按钮。
- JEI 另外提供 FTB Quests 物品提交、Distant Worlds Lithum 祭坛和 Project MMO 回收配方页面。

### HUD 与世界内提示

- **天华砧 / 锻造工具站 HUD**：准星指向机器时显示槽内物品、当前/所需锤击数、锻造炉温度、配方温区、余烬储量与单锤消耗、失误次数和无配方警告。工具站还会显示目标温度与温变率；HUD 底部同时显示温控范围、拉杆绑定、自动补货和自动锤炼状态。
- **遥远世界祭坛 HUD**：准星指向 Lithum 核心时显示祭坛空闲/工作状态、当前配方或产物、能量/上限、恢复速度，以及周围八个基座的物品与数量。该 HUD 可通过客户端配置 `distantWorlds.enableHud` 关闭。
- **合成进度 HUD**：执行异步合成时在屏幕右侧显示目标物品、总体百分比、完成/运行节点、当前步骤及机器状态；可在按 `P` 打开的进度界面中单独隐藏或恢复。
- **绑定提示 HUD**：手持可绑定的网络连接器并指向支持的机器或祭坛时，会在快捷栏上方提示当前操作是绑定还是解绑。

### 自动进食

打开 RS 合成网格后，可以直接使用网络里存放的食物：

- **多样饮食**：配合 SolCarrot，自动吃掉还没有记录过的食物。
- **堆叠暴食**：选择一种食物，自动吃到饱或达到单次上限。
- 堆叠暴食会识别“暴食的赞赏”等允许满饱食继续进食的效果。
- **膳食均衡**：配合 Diet，自动选择食物补充较低的营养组。
- 可以设置食物黑名单和状态效果黑名单，避免误吃不想使用的食物。
- 吃完后的碗、瓶子等容器会优先放回 RS 网络。
- 服务器可以设置使用条件、每次消耗的物品和单次进食上限。

### 村民交易补货

- 在村民交易界面选中一项交易后按 `Space`，自动补充两个付款槽，便于连续交易。
- 优先使用玩家背包中的匹配物品，再从当前可访问的 RS 网络提取剩余数量。
- 每个付款槽会补到其有效堆叠上限，而不只是补足一次交易所需的数量。
- 界面会显示来自背包和 RS 的补充数量，并明确提示部分补货、无网络、无提取权限或交易失效。
- 缺少的付款物品及数量会显示在交易界面，并自动加入 JEI 收藏。

### 其他顺手功能

- 在附魔台按 `Space`，可从存储网络补充青金石。
- 铁砧界面可以记住常用材料，以后从背包或网络快速补货；支持原版、Goety 和 Iron's Spells 铁砧。
- JEI 收藏的物品可用于保护村民交易，避免交易刷新模组把它重新随机掉。
- 建筑手杖 可以把网络里的方块也计入可用数量，建造时不必全带在身上。
- 在支持的 RS 网格安装 RSI 虚空升级，可按自选规则销毁新放入网络的物品。
- FTB Quests 的“领取全部奖励”可以继续处理领取后新解锁的任务奖励。

### 神化附魔图书馆

- 先把 Apotheosis 图书馆或末影图书馆绑定到 RS，打开图书馆界面后即可使用 RSI 附魔书导入面板。
- 扫描绑定 RS 网络中的附魔书，并按物品信息合并显示库存数量。
- 可以搜索附魔或附魔书信息、选择当前筛选结果，并导入筛选结果或全部兼容附魔书。
- 导入前会明确标记无效附魔书、不支持的自定义数据，以及被目标图书馆拒绝的附魔书。
- 扫描与导入均由服务端校验；未成功提交的附魔书会退回 RS，RS 无法接收时也会安全返还。
- 神化图书馆原生筛选框同时支持拼音和注册名搜索。

### 补货与物品管理

- **重铸台补货**：在 Apotheosis 或 Ancient Reforging 重铸界面按空格，自动从 RS 网络补充符石；缺少时会加入 JEI 收藏。
- **远程侧边栏**：按 `Y` 在其他界面查看和搜索 RS 库存，也可直接查看物品用途与配方。

### 特殊自动化兼容

- **Embers Rekindled** 可协助解出炼金台配方，并记住已找到的结果。
- **Aetherworks** 可以自动使用锻造砧、补充材料，并显示温度和进度。
- **Goety** 会准备受支持的仪式，但最终启动仍由玩家确认；长仪式也会按完整持续时间计算灵魂需求。
- Farmer's Respite 和 Youkai's Homecoming 的茶壶、蒸笼及发酵机器可参与递归合成，包括涉及流体的配方。

### 神化刷怪笼升级

- 手持有效的 RS 网络物品，潜行右键 Apotheosis 刷怪笼即可打开升级界面；手持 BD 终端时使用 `Alt + 右键`。
- 界面会列出当前可用的正向升级、完成状态、所需材料和 RS 库存数量。
- 可以同时选择多个升级，并在确认前预览完整的材料依赖与合成计划。
- 已有材料会从所连接的 RS 网络扣除；缺少材料且存在有效配方图时，会自动递归制作。
- 扫描和执行均由服务端校验玩家、网络、维度、距离、刷怪笼状态和已预览的选择。

### 容器一键转移

- 打开箱子、机器输入界面等容器后按 `F`，即可把容器中的物品全部转移出去。
- 按 `G` 可以切换转移目标：发送到已绑定的 RS 网络，或发送到精妙背包。
- 转移过程中会遵守过滤器、物品黑名单和目标容量；无法转移的物品会留在原容器中。
- 在聊天框、搜索框等文字输入界面中不会误触发转移。
- 在玩家物品栏和合成访问器等需要原版副手切换的界面中也会禁用 `F` 转移，让按键恢复原版行为。

### 共振磁盘

共振磁盘是一种特殊 RS 存储磁盘，盘内物品可以像玩家随身携带一样参与效果与资源查找。

- 支持属性、`inventoryTick`、事件驱动被动效果和兼容资源查询。
- 对配置为可变的物品保存 NBT/耐久变化，而不是只模拟一次副本。
- 默认支持 Apotheosis 药水护符、Muyimeng 混合药水护符、Reliquary 烈焰术士法杖、Enigmatic Addons 石英花、Forbidden & Arcanus 幽灵之眼护符。
- 支持勇三/月之石九剑书、Wizard Terra Curios 的 `BuffItem`、Terra Equipment 成组无限药水。
- 支持存放细雪桶、原液，毒液等的存放，存放后支持递归合成
- 支持将盘丢入井中，或者人跳入井中（需将盘放进RS，携带终端）获得虚空恩惠的能力，可解锁malum转化的能力
- 阻止共振磁盘被 RS 磁盘的 `Shift` + 右键快捷操作误拆成 4K 存储原件和元件外壳。
- 同一个 RS 网络只能启用一张共振磁盘，避免被动效果和资源重复计算。

### 精妙背包改造

- 可将精妙背包的磁铁、拾取、喂食、补货或存入升级连接到 RS 网络。
- RSI 还提供专用背包升级；安装 Majrusz's Accessories 时，压缩升级也可处理符合条件的饰品。

### 其他兼容性

集成层还覆盖 Miner's Delight 铜锅、改名后的 Terra Curio 工坊、History Stages 配方锁，以及 EMI 合成按钮位置适配。这些模块都会在运行时按安装情况加载，不会变成硬依赖。

### FTB 任务物品检测

- RSI 制作或放入网络的物品可以计入 FTB Quests 物品任务。
- 可以直接从网络提交任务物品、扫描哪些任务还缺材料，并把缺少的物品加入 JEI 收藏；侧栏按钮可单独关闭。
- 需要安装 FTB Quests 和 FTB Teams。如果整合包已有其他自动任务检测模组，RSI 会让它负责自动计数。

## 快速开始

1. 建造并供能一个 Refined Storage 网络。
2. 获取 RSI 网络连接器。
3. 潜行右键绑定单台机器，或按 `;` 扫描并绑定附近机器。
4. 在 JEI 打开配方并点击 RSI 合成操作。
5. 检查合成计划，选择替代配方或重复次数，然后启动。
6. 按 `P` 查看进度；完成后产物进入 RS，没有网络时进入玩家背包。

## 默认按键

所有按键都可以在 Minecraft 控制设置中修改；配置中的数字键码使用 GLFW 值。

| 按键 | 场景 | 功能 |
|---|---|---|
| `F` | 容器 / 存储终端 | 转移容器内容，或将当前 JEI/EMI 选中的物品填入搜索框 |
| `G` | 任意/容器界面 | 切换 RS / 精妙背包传输目标 |
| `Y` | 任意界面 | 显示/隐藏 RS 侧边栏 |
| `H` | 任意界面 | 显示/隐藏机器管理中心 |
| `P` | 任意界面 | 打开/关闭当前合成进度 |
| `;` | 世界中 | 使用手中、物品栏或饰品栏中的网络连接器绑定附近机器 |
| `Alt` + 右键 | 世界中 | 将手中的网络终端绑定到准星指向的机器 |
| `Alt` + 左键 | JEI 物品 | 按模组筛选 |
| `Alt` + 中键 | JEI 物品列表 | 清空搜索 |
| `Ctrl+T` | JEI 配方 | 传送到 RS 合成终端 |
| `Ctrl` + 左键拖动 | RS 格子 | 每格提取一个物品 |
| 左键拖框后按 `A` / `H` / `Esc` | JEI 列表 | 收藏 / 隐藏 / 清除框选 |
| `U` / `R` | 侧边栏悬停物品 | 在 JEI 查看用途 / 配方 |
| `Space` | 村民 / 附魔界面 | 从网络补充交易物品 / 青金石 |

自定义 GUI 默认包含 Crabber's Delight、Metal Barrels、PGP、EMX Arms、Apotheosis 和 Ancient Reforging。即使 RSI 不负责自动制作这些配方，也仍可绑定并远程打开它们的界面。

## 配置

配置文件本身包含注释和取值范围：

- `config/rs_integration/common.toml`：通用功能开关和可选模组联动。
- `saves/<世界>/serverconfig/rs_integration/server.toml`：服务器上的合成和机器行为。
- `config/rs_integration/client.toml`：侧边栏、显示选项、JEI 工具和 Tetra 预览设置。

配置文件内含说明和取值范围。升级时通常会保留已有设置；新增列表项可能需要手动补充。

## 诊断

- `/rsi cancel`：取消玩家当前合成链。
- `/rsi_debug`：向权限等级 2 的管理员提供合成链、账本、配方索引、处理器、绑定、解析追踪、审计、Embers 缓存/锁和性能诊断。
- `diagnosticVerboseLogging`：排查问题时启用详细解析与调度日志。
