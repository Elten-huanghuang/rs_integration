# RS Integration 1.4.2 后续更新公告合集

**整理日期：** 2026 年 9 月 9 日  
**覆盖范围：** `9a697a2..1352e59`  
**当前版本：** `1.4.2`

以下文案均可单独对外发布。

## 公告一：递归合成与大型任务稳定性更新

RS Integration `1.4.2` 已完成一轮递归合成与批处理稳定性更新。

- 动态 NBT、锻造升级和不可破坏装备现在可以继续参与递归合成，不会在升级链中丢失附魔、耐久或其他标签。
- 库存中已有的带 NBT 物品可以直接作为升级链起点，不再重复制作普通底材。
- 修复依赖少量种子启动、随后自我增殖的批量配方；前一批的真实产物可以继续供给后一批。
- 同类机器的大订单会持续分批派发，不再只执行第一批；大型任务的规划、结算和回调也改为分 Tick 推进。
- 配方索引、库存查询和动态目录检查进一步减轻了服务器主线程压力。

这轮更新主要面向长合成链、大容量存储和多机器并行场景，建议客户端与服务端同时更新。

## 公告二：配方界面与失败排查更新

RS Integration `1.4.2` 改进了 JEI、EMI 和任务失败后的操作体验。

- JEI/EMI 的合成按钮改用统一材质，并新增材料状态颜色：绿色表示当前直接材料至少够执行一次，红色表示不足，灰色表示等待或暂不支持。
- JEI 作弊模式新增权限校验后的快捷操作，可获取单个、获取整组或丢出完整展示堆叠，并保留物品 NBT。
- 合成失败时可打开详细报告，查看失败节点、配方、机器位置、任务进度和环境版本。
- 最近的失败报告可以重新打开，也可以导出为本地 UTF-8 文本；报告不会自动上传。
- 无效方块绑定和异常配方会更早被拒绝，减少“预览能通过、执行后才失败”的情况。

材料颜色只反映当前存储中的直接物品是否足够，不代表机器能源、结构和输出空间一定满足条件。

## 公告三：机器与模组兼容性更新

RS Integration `1.4.2` 扩充并修复了多项模组联动。

- 新增 Wishing Fountain 递归合成支持，以及 Crock Pot 鸟笼鹦鹉喂食的配方与批处理支持。
- 修复 Eidolon 火盆仪式的基座祭品、焦点物品、结构和生命值条件检查。
- 修复相邻 Botania 魔力池并行时的输出归属问题，避免把邻池物品认成自己的产物。
- 修复 Iron's Spells 动态法术目录刷新和损坏条目隔离，单个异常法术不再拖垮整个目录。
- 修复 Aetherworks 输入处理、Embers 输出恢复，以及部分容器和存储观察边界问题。
- 适配 Beyond Dimensions `0.7.30`，并加强异常物品身份和界面结构变化的隔离保护。
- 修复大型外部存储数量转换时的整数溢出，避免显示负数或产生虚假缺料。

同时使用上述模组的整合包建议更新后重新进入一次配方界面，让服务端重建最新配方目录。

## 公告四：CraftFlow 共存补丁

RS Integration `1.4.2` 新增 CraftFlow 共存保护。

当 CraftFlow 与 RSI 同时安装时，RSI 会隔离 CraftFlow 中与自身重复的配方按钮、服务端伪合成、无线机器绑定、输出捕获和自动进食入口，避免出现重复按钮、重复执行、物品归属冲突或两套绑定状态互相覆盖。

兼容层是可选加载的：没有安装 CraftFlow 时不会加载其类，也不会影响普通 RSI 环境；CraftFlow 类结构发生变化时，不兼容的钩子会自动停用，降低启动崩溃风险。

这项调整以 RSI 的合成、绑定和结算逻辑为准。若整合包此前依赖 CraftFlow 的同名功能，请更新后检查按键和界面配置。

## 公告五：GoeticLegacy 替代仪式修复

RS Integration `1.4.2` 已修复 GoeticLegacy 替代研究仪式的自动化问题，覆盖 `goeticlegacy:substitute_ritual_magic` 及同系列配方。

- 修复仪式看似空转、完成后 RSI 仍等待 `goety:empty_focus` 的问题。
- 该配方 JSON 中的空白法术聚晶只是运行时占位结果；GoeticLegacy 实际会根据激活卷轴生成带 `GoeticLegacySub` 数据的研究卷轴。
- RSI 现在会记录本次使用的激活卷轴，只领取物品类型一致且带有效替代研究数据的真实成品。
- 基座材料写入后会检查插入余量和实际槽位；任一基座没有完整放入材料时，任务会停止启动并进入恢复流程，不再无材料空转。
- 替代仪式不再以占位的空白法术聚晶登记为递归生产者，避免被其他合成链错误选作中间步骤。

配方自身的 `duration: 5` 表示 5 Tick，材料消耗非常快，肉眼可能只会看到短暂摆放；这不再影响 RSI 对真实结果的识别和结算。

## 统一升级提醒

- 当前文件名仍为 `rs_integration-1.4.2.jar`，请用构建时间或校验值区分旧包与修订包。
- 网络协议仍为 `45`，客户端与服务端必须使用同一份 JAR。
- 更新前建议备份世界与配置，并删除实例中旧的同名 RSI JAR，避免同时加载多个副本。
- 本轮修改不会主动清除存储内容、机器绑定、收藏或已有任务数据。
