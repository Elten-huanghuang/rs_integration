# RS Integration 1.5.0.5 更新公告

- 更新日期：2026 年 10 月 10 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 上一版本：1.5.0.4

本次更新加入余烬复刻机器的远程合成，并修复递归材料选择、桶装流体处理及机器缺能时的批量合成问题。

## 新增与兼容

- 支持余烬复刻（Embers Rekindled）的熔炼炉、混合离心器和压印锤：可绑定机器，通过 JEI / EMI 发起远程合成，并参与递归合成与批量加工。
- 压印锤直接捕获掉落的成品，无需在印模底座下放收集箱。已安装的正确印模会复用；印模不对时，可从存储网络取用现成印模，或递归制作后自动更换。
- 在配方与递归树中增加中文使用提示，标明余烬能量供应位置、流体存储要求，以及合成期间不能用外部管道抽走成品液体等条件。

## 问题修复

- 修复 Malum 的虚空恩惠配方使用多种灵魂作为候选材料时，递归树无法切换原材料的问题。以 `malum:void_favor/umbral_spirit_copy` 为例，现在可在材料节点选择灵魂，并按选择重新规划。
- 修复余烬机器批量加工时，上一轮材料尚在机器内或余烬能量暂时不足便立即报错的问题。任务会等待机器完成当前加工或补能后重试；持续无法恢复时仍按超时处理，并说明等待原因。
- 修复部分桶子类物品缺少 Forge 流体能力时，终端无法正确识别、导入或导出液体，以及相关容器转换配方处理不正确的问题。
- 改进缺少材料时的递归合成预览与错误提示，区分材料缺口和配方规划超时。
- 万界归墟盘无法读取时，悬浮提示会指出可识别的故障原因并给出对应恢复建议，包括缺失模组物品或流体、数据文件缺失及存档不匹配。

## 性能优化

- 优化终端库存搜索、流体容器索引和递归配方图的缓存与复用，减少大规模库存和配方下的重复计算。
- 缓存可选 Lodestone 配方类型的探测结果，避免缺少对应模组时反复探测和输出告警。
