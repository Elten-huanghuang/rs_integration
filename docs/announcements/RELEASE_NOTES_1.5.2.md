# RS Integration 1.5.2 更新公告

- 当前版本：1.5.2
- 首次发布：2026 年 10 月 20 日
- 公告整理：2026 年 10 月 24 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 公告范围：从版本号改为 1.5.1 起，到当前 1.5.2 的全部玩家可见更新。

本篇已合并 1.5.2 发布后陆续补充的内容，并删除重复说明。旧版磁盘、旧配置和已有机器绑定会尽量自动兼容，升级前仍建议备份世界。

## 本版重点

- 万界归墟盘现在可以同时保存物品、流体、魔力、魔源和灵魂。
- 超大数量的物品、流体和魔法资源可以正常显示、规划和合成，不再因为数量过大被截断。
- 新增共振魔力池、共振魔源罐、机器中心、自动合成黑名单和离线物品退款。
- 递归合成支持更多工作台、兑换配方、料理机器和实体机器，并可安全处理大批量任务。
- 合成计划可以选择并记住配方与材料，也可以指定某种材料只使用现有库存。
- 缺料、配方循环、机器不可用和计划过大等原因会分开提示，不再全部显示成“缺少材料”。
- 改善 TaCZ 弹药、Aether 炉具、巫术与魔法、Malum、拔刀剑及多套料理机器的兼容。

## 1.5.1 以来的机器与模组兼容

- 支持 Aetherworks 金属成型台，可远程绑定、递归准备材料并从 RS 流体库存供液。
- 支持余烬复刻微型锅炉，可递归制作沸腾配方并把气体产物存入 RS。
- 支持地牢乐事怪物锅，可绑定、远程打开、批量加工和多锅并行。
- 怪物锅会按原模组要求检查刷怪笼、地牢炉灶和污渍灯笼等热源。
- 支持苦旅春之冠配方，可从 JEI 按选中的花朵发起合成。
- 支持暮色乐事炽铁锅、BOSSes' Delight 灵魂锅、随意乐事炸锅、Farm & Charm 烹饪锅与烘焙机、烛火晚宴汤锅、烘焙屋小烹饪锅。
- 完善妖怪归乡烹饪锅与蒸笼，并支持输入预载、容器返还和多台机器共同执行。
- 支持共振盘中的 TaCZ 散装子弹参与换弹，换弹时按子弹口径和实际数量扣除。
- 枪械 HUD 会显示共振盘中的匹配弹药，并适配新旧版本 TaCZ 的 HUD 更新方式。
- 修复 Shift 快速存入共振盘时，背包扣除数量与实际存入数量不一致的问题。
- 修正 Aether 冷冻器、祭坛和孵化器的燃料选择。冷冻器除冰石外也会识别冰石台阶、楼梯和墙等可用燃料，祭坛和孵化器也会读取实际燃料表。
- Aether 冷冻器、祭坛和孵化器批量下单时会正确合并同种材料的多段数量，并让输入、燃料和实际加工次数保持一致，不再出现只装入一部分却按整批计算的问题。
- 修正多种机器的燃料、工具耐久和可重复使用材料的消耗规则，避免批量合成时多扣或少扣。
- 修复 Malum 祭坛粒子越界导致的客户端崩溃，并改善祭坛材料槽与灵魂供能。
- 修复 Aetherworks 工具站第一次自动锤炼时温度不足，以及锻座拉杆被拆后仍读取旧拉杆导致崩溃的问题。
- 修复奥术迭代器从终端直接批量合成、催化耐久和连续执行的问题。
- 修复拔刀剑魔改配方的妖力、锻造数和刀名匹配，复杂升级链可以正确递归规划。
- 修复魔金候选、魔凝机回收、附魔冷却器和部分机器批量容量判断。

## 魔法资源统一存取

- 万界归墟盘新增魔力、魔源和灵魂三类魔法资源，各自独立保存，不会和物品或流体互相换算。
- 混合终端可以查看魔法资源的储量、容量和占用，并参与搜索与筛选。
- 支持 Botania 魔力石板与魔力饰品、Ars Nouveau 魔源容器、Goety 灵魂图腾等物品直接存入或取出魔法资源。
- 手持创造魔力池或创造魔源罐在终端资源条目上右键，可以一次存入大量资源；创造物品本身不会被消耗。
- 魔法资源存入前会检查剩余容量。空间不足或中途失败时，未存入的部分会退回，不会先清空容器。
- RS 与 BD 的魔法库存保持独立。当前终端连接的网络决定使用哪一边，不会把两个网络的余额直接相加。
- 合成计划会显示魔法资源的总需求、当前可用量和预计缺口。
- `/rsi_debug` 可以查看魔法资源来自哪里、当前预留和剩余空间。

## 灵魂资源与共振容器

- Goety 黑暗祭坛、诅咒之笼、灵魂烛台和原生灵魂增减流程已经接入 RS 库存。
- 灵魂方舟可以从绑定的 RS 网络自动补充灵魂，默认关闭，防止无意消耗库存。
- 亡灵火炉递归合成可以使用虚拟灵魂烛台；该功能只用于 RSI 自动合成，手动点火仍要满足 Goety 原版结构。
- 新增共振魔力池，保留原版魔力池的灌注、火花、接收器、输出模式和液面效果。
- 新增共振魔源罐，可接收 Ars Nouveau 中继器、分流器和原生魔源设备的输出。
- 两种共振容器都能绑定 RS 网络，并显示储量、容量和绑定提示。
- 共振魔力池与共振魔源罐都由原方块和 4 个石英富集铁升级获得。

## 超大库存与磁盘

- 万界归墟盘中的单个物品、单种流体和魔法资源都可以保存特别大的数量。
- 旧版磁盘和旧数量格式继续兼容，加载时会自动整理重复记录，避免同一资源被重复计算。
- 混合终端、配方树和容器提示可以正常显示超大数量，完整数量会保留在详细提示中。
- 安装的模组暂时缺失时，只隔离对应物品或流体，其他库存仍可使用；原数据不会直接删除。
- 修复磁盘仓重新连接后物品或流体列表为空的问题。
- 磁盘操纵器新增快速分批搬运，可跨 tick 继续未完成的搬运，不再每 tick 只处理很少的资源。
- 磁盘操纵器遇到网络或磁盘暂时收不下时会等待一段时间再重试，减少重复检查造成的卡顿。
- 网格搜索缓存移动到 `rs_integration/cache/grid_search`，旧位置的文件会自动迁移。

## 合成计划与操作界面

- 候选配方改为可搜索的卡片列表，显示配方名称、机器类别和配方预览。
- 左键节点打开候选配方，左键卡片应用配方；卡片过多时可以搜索、翻页或使用键盘切换。
- 可以设置默认配方、默认材料，也可以禁用不希望自动使用的配方。
- 配方与材料选择会保存在当前游戏实例中，重新打开计划或重启游戏后仍然有效。
- 每个节点都可以使用“忘记”恢复自动选择，也可以把非目标材料设为“只使用库存”。
- “只使用库存”不会删除配方；库存不够时会明确提示，而不会继续制造该材料。
- JEI 配方书签新增“未收藏”“已收藏”“已收藏并禁止递归”三种状态。
- 右键书签可以收藏并禁止递归，再次右键可恢复；左键取消收藏时会同时清除禁用状态。
- 缺料、警告和可用机器数量会集中显示在合成次数附近，点击后可查看完整原因。
- 大量材料和剩余材料支持分页，不再挤在一行或撑出界面。
- 关闭正在计算的计划界面后，计划会在后台继续，完成后可在聊天栏重新打开。
- 混合终端会记住上次使用的资源分类，重新打开界面后不必反复切换。

## 递归合成与批量执行

- 工作台、物品兑换、流体容器转换、浸泡、市场兑换、温泉和虚空恩惠等配方可以批量执行。
- 大批量产物超过单组上限时会自动拆成多个正常物品堆，不会丢失超出部分。
- 可重复使用的催化剂、容器和工具不会随合成次数被错误重复消耗。
- 工具按实际耐久消耗规划，燃料按实际燃烧时间准备，机器会按照输入、输出和燃料空间安排批次。
- Farmers Delight 砧板缺少刀具时会先递归制作合适的刀或剪刀；工具仍按每次操作消耗 1 点耐久，合成完成后会正确归还。
- 同一台机器不会被多个合成任务同时占用，避免重复投料或产物归属混乱。
- RS、BD、磁盘和玩家背包可以共同参与材料准备；失败或取消时只退还未实际使用的部分。
- 修复切换维度或存储网络后，仍然固定使用旧网络并误报中间材料不足的问题。
- 修复 Malum 祭坛材料被拆成多个小堆后无法开始批量合成，以及 Wizards Reborn 秘蕴不足时准备失败的问题。
- 临时读取不到库存时会等待并重试，不再因为一次读取波动直接判定失败。
- 修复多个配方、机器或后台计划之间串用材料选择的问题，以及旧计划结果被重复使用的问题。
- 修复多产物重复结算、准备任务超时、重复输入槽共用库存和大批量库存统计错误。
- 修复大型配方图合并后顺序错误、依赖丢失、数量重复显示和切换计划后节点消失的问题。
- 修复压缩与分解配方形成循环时被误报为普通缺料的问题。
- FTB Quests 提交物品任务时，如果现有材料只够一部分，会先提交这一部分，再递归制作剩余数量。
- 合成执行重新区分机器投料和普通批量步骤，修复部分任务在材料已扣后再次启动而报错的问题。

## 配方选择与缺料排查

- 保存的默认配方会优先尝试，但条件不满足时仍可使用其他可行配方。
- 本次计划中手动选择的配方会作为明确选择，不会因为暂时缺料而悄悄换成别的配方。
- 从 JEI、EMI 或原版配方书直接发起合成时，当前点击的配方不会被以前的偏好替换。
- 配方切换失败时，原来的计划和节点选择仍会保留，方便继续查看或切回。
- 计划会区分普通缺料、没有可用配方、材料循环、计划过大、机器或世界条件不满足、结果过期和已取消等情况。
- 缺料诊断中可以一次收藏缺少的物品，也可以查看相关警告与候选机器。
- `/rsi_debug` 新增配方浏览器慢调用统计，方便定位第三方配方预览造成的卡顿。

## 机器中心、绑定与终端

- 终端侧边机器按钮和 `P` 管理入口统一为机器中心；有合成任务时会优先打开任务页。
- 全部绑定机器改为卡片列表，显示名称、维度、坐标、收藏、解绑和自动合成状态。
- 机器名称会优先读取机器自身或方块的实际名称，减少重复翻译和显示错误。
- 机器绑定改由服务器统一保存，终端物品里只保留稳定标识，复制终端或更新名称后不会丢失绑定。
- 绑定同步只发送有变化的机器，并分批传输，大量机器时更稳定。
- 自动合成黑名单同时作用于侧边机器、机器中心、JEI、EMI、计划候选和执行阶段。
- 右键单台机器可切换自动合成状态，拖动框选可以批量拉黑或恢复。
- 并行合成只计算未拉黑的机器，避免已停用机器继续占用任务位置。
- 修复打开未加载区块中的机器界面时意外加载区块的问题。
- 修复 RS 样板终端被 RSI 混合界面拦截、JEI 配方转移不完整和远程铁砧转移错误的问题。
- 修复背包同步覆盖鼠标当前物品、远程机器产物延迟显示和批量入库重复刷屏的问题。

## 物品与流体退款

- 取消、离线或背包已满时，未领取的物品会安全保存，重新登录后自动尝试放入背包。
- 背包仍满时，物品会保留在退款队列中，可通过 `/rsi_item_refund` 再次领取。
- 流体退款改为右键存入 RS 网络；网络空间不足时，未存入的数量继续保留在退款物品中。
- 无法手动存入或玩家离线时，流体退款会保留，可使用 `/rsi_fluid_refund` 领取。
- 旧版炼金流体凭据可以手持右键转换为新的退款物品。

## 重要兼容与崩溃修复

- 修复开发环境启动时过早读取配置导致的崩溃。
- 修复部分可选模组在启动早期被错误判断为已安装或未安装的问题。
- 修复召唤祭坛已经开始仪式后仍被误报为合成失败的问题。
- 修复食物带有异常营养值时拖累整次库存读取，导致其他正常材料也被误报缺少的问题。
- 修复机器卡片、收藏、黑名单、无界面机器和侧边入口状态不一致的问题。
- 修复磁盘仓重连、统一盘恢复、重复记录和流体容器识别问题。
- 修复批量合成时机器产物、剩余材料和退款重复结算的问题。
- 修复共享锅具配方类型、炸锅结果读取、料理锅无进展和批量启动问题。
- 修复新版 TaCZ 更换 HUD 方法后可能导致的启动错误，同时继续兼容旧版本。
- 补齐中英文提示和失败原因，减少界面显示原始文本或空白提示的情况。

## 常用配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `storage.diskManipulator.enabled` | `true` | 开启磁盘操纵器快速搬运；关闭后恢复 RS 原版速度。 |
| `storage.diskManipulator.budgetMicros` | `1000` | 所有磁盘操纵器每 tick 共用的处理时间。 |
| `storage.diskManipulator.maxOperationsPerTick` | `1024` | 单台磁盘操纵器每 tick 最多处理多少次。 |
| `storage.diskManipulator.maxItemsPerOperation` | 不限 | 单次最多搬运多少资源。 |
| `storage.diskManipulator.noProgressCooldownTicks` | `20` | 无法继续搬运时等待多少 tick 再重试。 |
| `magicResources.pinnedBackend` | 空 | 终端没有明确所属网络时，默认使用哪一边的魔法资源。 |
| `magicResources.creativeMagicDepositAmount` | `2100000000` | 创造容器一次存入的魔法资源数量。 |
| `integrations.enableGoetySoulReverseRefill` | `false` | 是否允许灵魂方舟从 RS 网络自动补充灵魂。 |
| `integrations.goetyBrazierVirtualCandleCount` | `64` | 自动合成亡灵火炉时使用多少个虚拟烛台。 |
| `craftingMaxGraphNodes` | `16384` | 单次合成计划最多包含多少配方节点。 |
| `craftingPlanCacheMaxNodes` | `131072` | 后台计划最多保留多少配方节点。 |
| `craftingStableBatchRetrySeconds` | `5` | 库存暂时不可读取时最多重试多少秒。 |
| `craftingVirtualExchangeBatchLimit` | `0` | 纯兑换每批最多执行多少次；`0` 表示不额外限制。 |
| `machineTabThreshold` | `5` | 机器较多时何时自动改用机器中心。 |

料理机器还可以分别关闭输入预载并调整上限。默认上限均为 `64`，实际数量仍会受到材料、容器、输出空间和配方耗时限制。

相关配置项包括：

`enableTwilightDelightFieryPotInputBuffer`

`enableYoukaisHomecomingCookingPotInputBuffer`

`enableYoukaisHomecomingSteamerInputBuffer`

`enableLetsDoCookingPotInputBuffer`

`enableBossesDelightSoulCookingPotInputBuffer`

`enableCasualnessDelightDeepFryingPanInputBuffer`

## 升级提醒

- 升级前请备份世界，尤其是已经使用万界归墟盘、机器绑定和离线退款的存档。
- 第一次进入世界时会建立服务器机器绑定记录，并把旧终端中的机器列表迁移过去。
- 多人游戏请让客户端和服务端使用同一份 RSI JAR，只确认版本号相同还不够。
- 新的配置项通常会自动生成，旧配置会尽量保留。
- 魔力、魔源和灵魂只会在对应模组已安装且兼容开关开启时出现。
- 配方与材料偏好保存在当前游戏实例的 `rs_integration/crafting_plan.json`，不按服务器或存档分开保存。
- 如果某条配方没有自动使用，请检查“只使用库存”、配方卡片禁用状态和 JEI 红色书签。
- 服务器如果更在意流畅度，可以降低磁盘操纵器处理时间或每 tick 操作上限。
- 发布文件名为 `rs_integration-1.5.2.jar`。
