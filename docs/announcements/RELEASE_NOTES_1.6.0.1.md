# RS Integration 1.6.0.1 更新公告

- 更新日期：2026 年 11 月 15 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 上一版本：1.6.0
- 公告范围：以 [1.6.0 更新公告](RELEASE_NOTES_1.6.0.md)为基线，汇总此后的功能、优化与修复。

本次更新新增**材料来源多选**和**界面主题快捷切换**，继续优化大型递归计划，并修复材料变体分配、机器产物回收及远程终端兼容问题。

## 材料来源多选

- 递归合成树底部原“库存数量自动更新”位置改为“**材料来源**”按钮，点击弹出多选框，可分别启用**物品栏、存储网络、精妙背包**，默认全部勾选。存储网络项适用于当前所选 RS 或 BD 网络。
- 勾选或取消后保持多选框展开，方便连续调整；点击外部或按 Esc 收起。修改后自动重新规划。
- 来源选择同时影响**规划、库存提示和实际取料**，关闭某个来源后不会继续从该来源补取原材料。
- 修正底部材料来源、执行模式、产物去向及确认按钮的垂直对齐，统一文字基线；窄窗口保留两行布局，避免控件重叠。
- 选择自动保存到游戏目录的 `rs_integration/crafting_plan.json`；重开界面后保留，旧配置默认启用全部来源。

## 界面主题与玻璃效果

- 递归树、计划列表和合成监控器新增**调色盘按钮**，点击展开分页主题轮盘，可查看配色预览并选择主题；支持鼠标、滚轮、方向键、Tab 和回车操作。
- 提供 **14 套预设主题**：森林绿、冰川蓝、丁香紫、暖纸色、原版灰、黄铜工坊、绯月秘法、石英终端、樱霞、余烬、石墨、高透磨砂玻璃、高透黑玻璃和宇宙深空，并保留自定义模式。
- **递归树与监控器独立保存主题**，计划列表跟随监控器。切换后立即生效并自动保存，保留当前搜索、树缩放、节点选择和监控滚动位置。
- 磨砂玻璃对场景背景进行模糊，黑玻璃保留清晰背景；调整透明底板、细边框和状态色，避免多层边框叠加泛白，并修复后处理深度遮挡界面的问题。
- 预设不会改写已有自定义颜色，切回 `CUSTOM` 即可恢复。游戏内配置界面同样支持选择主题；配置路径和预设说明见[界面配置文档](../config/plan-ui.md)。

## 大型计划与预览优化

- 优化深层依赖图的可达性探测、状态维护与查询缓存，减少大型递归规划的重复搜索。
- 统一不同规划入口的路线选择与覆盖判定，修正库存查询和路线判断不一致的情况。
- 优化大规模合成树的布局、搜索和可见区域绘制，减少大型计划浏览时的开销。
- 保留配方浏览器首次点击的目标身份，页面重算后仍可复用对应预览，减少重复规划；切换根配方时按新的目标判断。
- 流体容器目录改为分片构建，配方索引与容器目录按同一代结果发布，减少构建期间的不完整查询。

## 材料分配与产物回收

- 修复机器材料的变体分配，优先使用已有库存，避免满足配方的材料被错误拆分或遗漏。
- 统一机器主动回收产物的持有和批次结算，完善串行、并行、取消及恢复流程，减少已取出产物与任务进度的对账偏差。
- 完善原版炉、铁炉、天境炉及外部标准执行器的产物交接，保留实际超额产物的处理。
- 修复远程机器预览确认时的上下文传递，并补充执行前复验日志，便于排查预览可用但确认失败的问题。

## 兼容与开发者接口

- 兼容 JEI 新旧输入接口，避免加载不适用的旧混入导致启动失败。
- 修复 RS 远程合成终端初始化和搜索框为空时的处理。
- 整理对外集成 API 的注册、排序、冲突匹配与生命周期检查，保留现有公开签名及诊断语义，并补充接口文档。
- 修正精妙存储磁铁升级兼容测试的方法签名判断。

## 升级说明

- 版本号为 **1.6.0.1**，对应文件名为 **`rs_integration-1.6.0.1.jar`**。替换旧版 RSI JAR 后重启游戏或服务器，客户端与服务端使用相同版本。
- 保留已有配置。材料来源首次升级默认全选；主题默认保留自定义配色，选择预设后也可切回恢复原配色。
- 材料来源保存在 `rs_integration/crafting_plan.json`；主题选择保存在 `config/rs_integration/client.toml` 的 `[craftingUi]`，其中 `treeTheme` 控制递归树，`theme` 控制监控器和计划列表。
