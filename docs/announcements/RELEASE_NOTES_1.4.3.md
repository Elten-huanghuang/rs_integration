# RS Integration 1.4.3 更新公告

**发布日期：** 2026 年 9 月 14 日

## 新增

### RS 虚空升级

- 新增可安装到 Refined Storage 网格过滤槽位中的“RS 虚空升级”，用于自动销毁进入对应 RS 网络且匹配规则的物品。
- 每个升级拥有独立配置，可按具体物品、物品标签和模组来源建立多条规则，并支持黑名单、白名单及规则组合。
- 配置界面支持从物品栏或 JEI 拖入幽灵物品，不会实际拿走玩家物品；规则写回服务端前会校验数量、标识符和权限。
- 同一网络中的多个升级由网络级协调器统一编译和执行，物品变化会进入有界队列处理，避免每次网络变动都完整扫描所有规则。
- 新升级默认为空规则，不会在未经配置时销毁物品；模拟插入、退款和任务恢复不会被当成应销毁的真实变化。

### 自动进食多选与快捷菜单

- 自动进食黑名单支持批量选择、范围选择和统一提交，管理大量食物时不再需要逐项保存。
- RS 网格中的自动进食入口改为可展开的紧凑菜单，并记住客户端的展开状态。
- 客户端选择状态、服务端偏好和黑名单同步使用明确的数据包边界，旧状态不会在切换网络或重新进入界面后覆盖新选择。
- 加强自动进食的权限、速率和库存变化校验，避免连续操作产生重复请求或使用已经失效的候选物品。

### 奥法炉灶与烹饪锅

- 新增 Iron's Spells 'n Spellbooks 奥法炉灶对 Farmer's Delight 烹饪锅和煎锅配方的递归合成支持。
- 奥法炉灶会优先临时调用玩家法力供能；法力不足时可从所选存储网络提取奥术源质或灰烬源质。
- 规划阶段会显示燃料条件，执行阶段仍会重新验证炉灶、燃烧时间、空闲槽位和实际配方，避免预览后环境变化导致错误扣料。
- 灰烬源质提供永久燃烧状态；普通燃料不足以覆盖完整配方时间时会保留明确提示，不会静默启动无法完成的任务。

### 专用远程 GUI 绑定

- 新增 Apotheosis 强化台（`apotheosis:augmenting_table`）的精确绑定，可从 RSI 侧边栏或机器入口远程打开原生界面。
- 新增 Goety 黑暗铁砧（`goety:dark_anvil`）的精确绑定，可远程打开原生界面而不把它误判为黑暗祭坛或其他 Goety 合成机器。
- 新增 Iron's Spells 'n Spellbooks 法术抄写台（`irons_spellbooks:inscription_table`）的精确绑定；点击双方块结构的任意一半都会归一到能够正确打开菜单的主位置。
- 新增附魔台的远程绑定
- 上述绑定均为“仅远程 GUI”类型，只显示机器操作入口，不注册自动合成能力，也不会影响同模组已有的卷轴锻造台、奥术铁砧、祭坛或其他机器绑定。

## 改进

### JEI框选优化

- JEI批量框选后可使用ctrl+左键取消具体的框选内容，操作逻辑和Windows一致。

### 大批量合成与服务器负载

- 并行组不再为整份订单展开 `操作次数 × 材料规格数` 的临时材料列表；材料需求改为按批次聚合并按需生成，显著降低单一配方超大订单的内存分配和主线程遍历。
- 批量调度改为使用有界物理批次和增量派发，仍会利用空闲的同类机器并发，不会通过全局串行队列限制正常机器吞吐。
- 提取账本按实际批次记录和结算，减少重复复制、重复物品匹配及失败恢复时的全表扫描。
- Refined Storage 与 Beyond Dimensions 的库存访问增加快照和索引复用，批次内相同材料查询不再反复扫描整个网络。
- 大任务继续分 Tick 推进；新优化只减少规划、分配与账本开销，不改变配方次数、材料扣除、产物归属或退款规则。

### 递归规划与机器选择

- 规划器加强对运行时 NBT、动态输出和旧版计划树的兼容，避免带状态物品在递归链中被错误替换为普通物品。
- 候选配方会结合实际可用的机器类型和绑定状态提前裁剪；没有兼容机器的路径不会再被选入可执行计划。
- 多台候选机器会分别保留不可用原因，Goety 祭坛等多方块机器可在计划中显示具体位置、状态和拒绝原因。

### 中间产物参与FTB任务判定

- 递归合成中已确认产生的主产物会同步到 FTB Quests
- 包括随后被下游配方消费的中间产物；容器返还、退款和模拟变化不会重复计数。

### 配方界面与操作反馈

- JEI 配方按钮的位置计算和生命周期处理更加稳定，界面重建时不会保留失效的按钮区域或错误复用旧材料状态。
- JEI/EMI 对同一配方只过滤极短时间内的误双击；规划较慢或请求失败后可以正常重试，不再出现长达 1.5 秒的无反馈状态。
- 服务端拒绝过于密集的预览请求时会向玩家显示“请求处理中”，并且被拒绝的请求不会持续延长限流窗口。
- 缺料提示改为以结构化材料账单为准。即使解析器诊断文本为空，也会完整显示每种短缺材料及实际缺少数量，并保留单项收藏功能。

## 修复

### 机器执行与物品恢复

- 修复 Malum 祭坛在动画过程中短暂清除制作状态时被误判为完成的问题；现在以真实成品实体或已捕获输出确认完成。
- Malum 任务取消或失败时会先登记机器和基座中实际回收的物品，再由提取账本补足其余退款，避免重复返还或遗漏物理输入。
- 修复 Malum 精魂坩埚动态配方刷新、输出识别及槽位恢复的边界问题。
- 修复 Goety、Iron Furnaces 和部分原版锻造链在机器类型、运行时输出或候选绑定变化后继续使用过期计划的问题。
- 修复机器原生批次和 RSI 调度批次边界不一致时，进度提前完成、剩余操作未派发或结算数量不一致的问题。
- 修复堆叠暴食模式一直吃的问题，
- 修复了下界合金背包升级失败的问题。
- 修复了部分情况下精魂坩埚无法获得加速的问题
- 修复了新生魔艺部分情况下找不到机器的问题

### 容器、搜索与界面兼容

- 容器快速转移会跳过只用于显示或模拟交互的假槽位，避免向 JEI、配方预览及其他虚拟槽位发送无效移动请求。
- 修复第三方模组物品提示类缺失或链接失败时拖垮 RS 搜索索引的问题；异常提示只隔离对应物品，其他搜索结果仍可继续建立。
- 改进 RS 搜索索引的后台发布和失效处理，旧索引结果不会覆盖更新后的搜索文本。
- 修复部分配方浏览器界面切换、材料状态缓存失效和按钮区域重排后的点击偏移问题。

## 升级说明

- 模组版本升级为 `1.4.3`，发布文件为 `rs_integration-1.4.3.jar`。
- 网络协议从 `45` 升级到 `47`，加入 RS 虚空升级配置及自动进食偏好同步。客户端与服务端必须同时更新到 `1.4.3`。
- 服务端配置结构仍为版本 `6`，无需删除现有配置文件；新增客户端偏好和功能配置会由 Forge 自动补全默认值。
- RS 虚空升级不会自动安装或生成规则，升级后不会主动销毁现有网络物品。
- 本次更新不会主动清除存储内容、机器绑定、收藏、共振数据或已有合成任务进度。升级重要存档前仍建议备份世界和配置，并删除实例中的旧版 RSI JAR，避免同时加载多个版本。
