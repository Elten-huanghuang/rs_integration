# RS Integration 1.5.0 更新公告

RS Integration 1.5.0 是一次以存储、递归合成和终端体验为重点的大型更新。本版本加入物品与流体混合终端和“万界归墟盘”，扩展递归合成与流体配方处理，新增多项模组兼容，并集中修复 FTB Quests、合成计划、统一磁盘数据和界面显示问题。

## 一、全新的物品与流体混合终端

- 新增物品与流体混合终端，默认开启。
- 物品和流体可以在同一个列表中搜索、筛选、存入和取出，不需要在物品终端与流体终端之间来回切换。
- 支持从终端向容器装入流体，也支持将容器中的流体倒回网络。
- 优化物品、流体条目的同步和客户端显示，减少打开终端时库存列表短暂显示旧数据的问题。
- 增加流体转移失败后的恢复处理，避免容器交互中出现流体或容器状态不同步。
- 终端交互支持 JEI 配方转移和过滤状态同步，混合列表中的物品与流体可以分别执行对应操作。

## 二、万界归墟盘

### 存储能力

- 新增“万界归墟盘”统一存储磁盘，将物品和流体存放在同一枚磁盘中。
- 支持物品、流体的统一数量汇总和快速查询，优化带 NBT、结构数据或其他身份信息的物品识别。
- 改进大规模库存下的索引、缓存和查询路径，并补充多种存储容量、增长和兼容性检查。
- 归墟盘可以接入 RS 驱动器、网络存储缓存和存储操作设备，也能正确参与机械臂、搬运器等自动化设备的存取。
- 增加归墟盘配方、JEI/EMI 提示和物品模型，补全客户端可见性与配方浏览支持。

### 数据安全与旧盘处理

- 修复归墟盘读档时可能造成的区块加载死锁。
- 归墟旧盘可按配置自动扩容，并保留原有库存；升级后无需手动拆分或重新整理磁盘内容。
- 改进磁盘数据持久化和文件写入校验，保存失败时保留待保存状态，避免错误覆盖有效数据。
- 增加磁盘掉落保护，降低磁盘从设备中掉落或设备被破坏时的丢失风险。
- 增加基于 UUID 的归墟盘找回机制和恢复命令，管理员可以处理意外丢失的磁盘。
- 优化磁盘挂载、卸载和网络重建时的生命周期处理，减少重复刷新和无效重建。

升级前请备份世界存档和 `config/rs_integration` 配置。首次加载旧版归墟盘时，请等待存储数据完成加载并确认库存正常。

## 三、递归合成与流体配方

- 支持概率材料的递归补做：合成计划会根据实际产出和概率重新规划不足的材料。
- 改进候选配方侧栏和替代配方选择，减少配方过多时找不到合适配方的问题。
- 修复合成目标物品、铁魔法墨水和部分流体产物在计划界面中显示错误的问题。
- 修复配方树渲染、计划预览和失败计划返回时的状态更新问题。
- 新增流体容器配方分类，支持桶、瓶子和其他容器的装液、倒液、容器返还与递归执行。
- 流体容器配方支持 JEI/EMI 浏览、收藏和配方转移，并在执行前检查流体产物是否有足够的网络存储空间。
- 兼容巫法重生（Wizards Reborn）炼金机，支持配方识别、机器绑定、批量执行、液体与容器处理、递归规划和失败恢复。
- 修复炼金机的墨水显示、进度同步和配方预览，并改进炼金锅的墨水补充。
- 为多种需要水的机器提供网络补水，补水机器列表和免费水配置可以独立调整。
- 改进流体产物的存储预检，避免在材料已消耗后才发现网络无法容纳产物。

## 四、模组兼容与自动化修复

- 修复召唤祭坛绑定机器的选择逻辑，现在会按距离选择合适的祭坛，减少远处祭坛被错误使用的情况。
- 修复召唤祭坛催化剂与消耗材料的区分，以及批量执行时的投料处理。
- 修复巫法塔罗仪式的灵魂能量结算。
- 修复更多熔炉升级后批量合成的燃料消耗计算。
- 为精妙背包的次元磁铁增加世界流体采集升级，并加入可配置的世界流体采集开关。
- 次元磁铁支持 JEI 液体过滤、幽灵槽筛选和容器/升级提示，减少误采集不需要的流体。
- 修复 FTB Quests 扫描时重复复制 NBT 导致的卡顿。

## 五、JEI、EMI 与配置界面

- 在 JEI 界面增加 RS Integration 配置入口，无需手动寻找配置文件即可打开配置界面。
- 新增完整的配置编辑界面，按客户端、服务端、存储、合成和模组兼容分类展示选项。
- 支持编辑、保存、重置配置，并提示需要权限或重启才能生效的选项。
- 完善 JEI 书签、配方页面和配置按钮的布局，兼容不同 JEI 版本的按钮位置。
- 修复 JEI/EMI 配方按钮、流体容器配方分类和部分配方转移按钮的显示位置。
- 修复配方树在部分配方、替代配方和流体配方下的渲染问题。
- 更新配置说明和中英文语言文本，补充新增机器、磁盘、流体和终端功能的提示。

## 六、界面与美术调整

- 统一磁盘提示为鎏金主题，优化名称、容量、存储统计和状态信息的排版。
- 为磁盘提示增加呼吸流光效果，使容量变化和状态信息更容易辨认。
- 万界归墟盘使用独立的鎏金名称和提示主题，与其他磁盘区分显示。
- 恢复共振盘原有配色和流光字体，避免共振盘与归墟盘使用同一套颜色。
- 补全万界归墟盘龙首贴图、物品模型和相关客户端显示控制。

## 七、问题修复汇总

- 修复 FTB Quests 扫描重复复制 NBT 导致的卡顿。
- 修复配方树和合成计划中的目标、墨水及流体显示。
- 修复召唤祭坛、巫法塔罗和更多熔炉联动中的计算问题。
- 修复统一盘读档时的区块加载死锁和旧盘扩容后的库存保留。
- 修复磁盘主题、名称样式和提示效果相互覆盖的问题。

## 升级说明

- 版本号：`1.5.0`
- Minecraft：`1.20.1`，Forge。
- 多人游戏中，客户端和服务端请同时更新，并使用相同版本的 RSI。
- 旧版配置可以继续保留；新增配置项会在启动时自动补全。配置文件位于 `config/rs_integration`。
- 升级前建议备份世界存档、配置文件以及包含重要物品的 RS 磁盘。
- 含有万界归墟盘的存档首次启动时，请等待存储数据加载完成后再进行拆盘、搬运或批量合成。
