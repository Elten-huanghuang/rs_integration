# RS Integration 1.6.1.1 更新公告

- 公告更新日期：2026 年 11 月 26 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 公告范围：以 [1.6.1 更新公告](RELEASE_NOTES_1.6.1.md)的最后一次更新（`b69cc0c8`）为基线，汇总截至 `84f2a21b` 的新增内容。

本次更新开放第三方合成材料源和一键进食食物源，统一合成计划与监控器的机器管理入口，并修复预览缺料、机器自动合成及退料问题。

## 一键进食

- 支持由第三方提供食物。优先从所选网络提取对应变体，确认缺货后才尝试注册来源；提取与食用前均按实际物品变体校验，包括 NBT 和 Forge 能力数据。
- 修复来源撤回、食用校验失败或费用只扣除一部分时的退还处理，按实际暂收的费用和已取得的物品结算。成功进食后正常处理返回的碗、瓶等容器。
- 修复 Diet 和 Spice of Life: Carrot Edition 的营养或食物记录联动。多样饮食模式在单次记录失败时仍可继续本批次，已吃下的份数照常反馈。

## 合成计划与执行

- 合成计划、合成监控器和机器管理可在同一界面中切换；从监控器进入机器管理或重命名后，可以返回原页面。
- 修复合成预览传输时丢失材料 NBT、炼金配方因空 NBT 无法确认，以及预览右上角漏报缺料的问题。暂不能列出缺料明细时也会提示「缺少材料」。
- 实时库存同步会在外部材料来源或分配数量变化时刷新预览和报价，即使库存总量没变也会重算。确认时若需要更换来源或增加外部份额，会先返回新计划再次确认。修复中间产物补料时漏判可用外部材料的问题。
- 修复共振盘虚拟合成误报缺少机器绑定，以及直接交付产物的任务无法并行启动的问题。

## 机器与模组联动

- **Farmer's Respite 与 Youkai's Homecoming 水壶**：修复自动合成、流体装瓶及容器返还。按实际装瓶规则计算配料、容器和产物数量，不再按同名物品或固定瓶容量推算。
- **魔凝机与天境冷冻器**：魔凝机按整批任务检查青金石燃料，并提示所需量和可用量；修复天境冷冻器的预览误判机器绑定。
- **魔法食事与烹饪锅**：修复雷云棉花糖预览漏算盛装容器和对应流派卷轴的问题。烹饪锅可使用符合配方的附魔铁掌，保留其实际标签；启动失败时正确退回未消耗的材料。
- **JEI 铁砧**：不再把仅供展示或不符合网络格式的配方 ID 发给服务端，避免查看相关配方时掉线。
- **Wizards Reborn、Malum、Eidolon**：移除已被通用合成流程替代的旧合成网络入口，修复 Wizards Reborn 迭代加工的材料回收。Forbidden & Arcanus 的现有入口保留。

## 存储与物品返还

- 修复切换工作站后重新打开终端可能复制物品的问题。工作站和侧栏退回 RS 的物品按玩家存入处理，避免被运行中的合成任务当成产物认领。
- 修复进食退款、任务提交返还、背包补货等流程中的回存处理，以及建筑杖余量和磁盘操纵器反向返还被合成任务认领的问题。磁盘主动供料行为不变。
- 万界归墟盘可恢复 `Damage` 标签缺失或取值不同、但实际耐久相同的旧条目，并按恢复后实际保留的条目统计载荷。
- 批量转移跳过菜品配方书，避免将配方模板当成实际库存。

## 开发与构建

- **Integration API 1.3** 新增第三方递归合成材料源、按来源的材料份额、客户端取物输入协调和服务端统一取物接口，支持 JEI 和世界选块等场景。
- **Integration API 1.4** 新增一键进食食物源注册。相关接入方式、优先级与结算规则见 [开发者 API 文档](../api/README.md#18-原生交互扩展)。
- 主模组编译和打包所需的模组 JAR 随仓库提供，补齐农夫乐事 1.2.8、1.3.3 及其他兼容测试依赖，并按模块去除重复测试。

## 升级说明

- 用 `rs_integration-1.6.1.1.jar` 替换旧版。网络协议已更新，联机时客户端与服务端须同步升级。
