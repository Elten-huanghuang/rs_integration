# RS Integration 1.5.3 更新公告

- 更新日期：2026 年 11 月 2 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 上一版本：1.5.2.4
- 公告范围：对照已发布的 1.5.2.4 公告，汇总升级至 1.5.3 的新增功能、改进与修复；同一功能的相关变化合并说明，已发布内容不再重复。

本次更新新增**共振经验杖与液态经验**，将**点餐终端**并入 RSI，加入 **Goety 女巫坩埚笔记本界面**。点餐终端进一步加入拼音搜索、收藏和食物详情；递归合成改进材料到达后的等待恢复与规划准备，并继续修复概率产出、市场兑换、炽炉双通道及归墟盘资源隔离等问题。

## 共振经验杖与液态经验

- 新增**共振经验杖**，手持时按**蹲下 + 右键**打开设置，可查看当前等级、网络液态经验和杖内暂存量，并调整目标等级。
- 支持**仅存入、仅提取、保持等级、关闭**四种模式：多余经验可自动存入网络，等级不足时可从网络补足；保持等级模式会自动双向调节。
- 支持手动存取指定等级、全部存入、全部提取，以及停止当前手动存取；手动存取会关闭自动等级控制，避免随即反向存取。开启自动功能后放在主手、副手、背包或当前可访问的共振磁盘中即可工作，同一玩家只启用一根经验杖，优先使用随身已启用的杖。
- 新增**经验修补**开关，消耗网络液态经验修复带有经验修补附魔的手持装备、护甲和已装备的 Curios 饰品；每 5 tick 最多使用 20 点经验，沿用物品自身的修补倍率。
- 新增 RSI **液态经验**，换算为 **1 点经验 = 20 mB**。经验杖使用玩家当前可访问、支持流体存储的 RS 或 BD 网络，液态经验也可由储罐和管道保存、传输。
- 新增经验杖的生存合成配方。空玻璃瓶可从网络装入 140 mB 液态经验，制成附魔之瓶；该容量按原版附魔之瓶随机经验掉落的平均值 7 点折算。装瓶只支持注入，不能把附魔之瓶反向排空；投掷后仍由原版随机决定实际经验。
- 精妙背包的液态经验输入 RS 时，会按相同 mB 数量转换为 RSI 液态经验；未被网络接收的余量仍保留原流体，不会把其他模组的经验流体一概按同一比例转换。
- 存取按实际收到的流体和实际增减的经验结算，未完成入库的余液保留在杖内；后端提交结果不明时暂停工作并显示提示，避免重复提交。高等级经验计算使用长整型，避免受原版总经验计数上限影响。
- 为经验杖加入独立立体模型、旋转环与动态光核，并提供专用设置界面及液态经验动画贴图。

## 点餐终端

- 将原 `rsfoodorder` 附属的食物点单功能并入 RSI，新增内置**点餐终端**，手持右键即可打开食物列表。
- 默认列出当前玩家未吃过的食物，支持搜索和“仅可做”筛选，并区分材料就绪、缺料、机器未绑定、配方未解锁和没有配方等状态。
- 支持**点一份**和**全部下单**，使用 RSI 配方检查、存储材料与已绑定机器完成制作；列表构建和订单提交分步进行，减少集中处理大量食物时的卡顿。
- 搜索支持中文、全拼、拼音首字母、物品 ID、多关键词和跳字模糊匹配；可切换全部、可下单、收藏列表或按饱食度排序。食物收藏保存在客户端配置目录，重新进入游戏后仍会保留。
- 修复视图筛选下拉菜单展开后点击界面其他区域仍残留焦点的问题；现在会关闭菜单，并正常处理被点击的控件。
- 详情区复用物品提示信息，并展示饱食度、饱和度和缺少的配方材料；已安装 AppleSkin 等食物提示模组时保留其扩展显示。
- 已吃记录会与 Sol Carrot 合并；旧附属的点餐终端物品 ID 和已吃记录可迁移。新增食物点单配置，可控制功能开关、跳过已吃食物、批量上限、刷新预算及下单间隔。

## Goety 女巫坩埚

- 新增笔记本式酿造界面，可搜索、选择药剂效果与强化等级，查看库存、材料需求、容量占用、灵魂费用和成品预览；自动推荐容量，并补齐各等级强化与药剂形态所需的前置材料。
- 手持已适配的网络访问器右键或蹲下右键坩埚可打开界面，主手为空、副手持访问器时也可使用；清水锅可直接打开，已有药液、废液、材料或正在炼制时需先处理原有内容。
- 坩埚直接使用玩家当前授权的默认 RS 或 BD 网络，无需单独绑定，从背包及该网络取料；材料目录读取当前 Goety 配置和数据包，同效果、同等级且满足原配方规则的材料可以替换使用。
- 支持为缺少的普通材料发起递归合成，按实际库存持续补齐；关闭界面、切换网络或订单失败时，清理检查任务并取消未完成订单。数据包重载后关闭旧界面，避免继续使用过期配方。
- 提供一键补水、一键炼制、装瓶和清理失败状态操作；缺料递归合成后自动投料并调用原生搅拌，巨勺可位于背包、副手或当前网络。灵魂供能与亡灵火炉共用，无实体烛台时使用虚拟烛台，默认 64、上限 1024，按实际进度扣费；保留原生热源要求。投料失败时恢复坩埚并退还未交付材料；修正满锅动画水位和创造模式容器交互的重复结算问题。
- 增加 Goety 多版本适配，已验证 2.5.36.1、2.5.52.4、2.5.60.1 的编译兼容；修复与 RevelationFix 同装时酿造预演触发异常退出分支的问题。2.5.60.1 新增的原生 `goety:cauldron` 制作配方仍由 Goety 自身处理。
- 新增 `integrations.enableGoetyCauldron` 独立开关，默认开启，受 Goety 总开关约束；关闭后停用 RSI 坩埚界面、补水及自动炼制，保留原生坩埚及已有数据，修改后需重启游戏。

## 递归规划与计划界面

- 库存充足的材料、缺料叶节点和生产步骤都可展示并改选生产配方；选择砧板等需要耐久工具的配方时，会使用适用的规划路径，不再忽略显式选择。
- 修复计划图丢失原配方布局、备选配方和材料角色的问题。有序工作台保留真实格子排列，单次材料与批次数量分开显示，并保留执行图中的精确 NBT 身份。
- 合并等价生产分支和连续复制阶段，汇总实际执行次数、净产量及并行信息；同一批产物的成本只展开一次，输入状态或材料角色不同的步骤仍分别显示。
- 修复复制、自增配方把已有种子当成本次新增产量的问题，按“现有数量 + 本次净增量”计算，并保持玩家选定的复制配方；多个后续槽位需要同一种复制材料时，先补足合计需求，避免提前用光种子导致后续缺料。
- 修复共用同一种物品、但流体或 NBT 状态不同的输入被误判为配方自消耗的问题。
- 修正工具耐久与单次损耗的换算，不可损坏工具可以覆盖整批操作，避免重复放大工具需求。
- 统一概率产物结算：固定次数订单交付真实产出，允许未命中；递归供料按真实到齐数量判断，必要时在尝试上限内补做，不会把尚未出现的概率产物提前交给下游。
- 必出主产物与概率副产物分别处理，砧板等配方不再因某个额外掉落未出现而整单失败；未能达到目标数量时给出专门原因，已获得的产物继续保留。
- 修改次数后立即确认，会先等待最新预览完成；过期响应不能覆盖新输入或触发合成。改变配方、数量、产物去向或关闭界面时取消待执行确认，预览失败后可重试。
- 修复界面重建后合成次数被旧计划重置的问题，并为 FTB Quests 提交预览补齐请求关联；机器忙碌、未加载或不可用的等待提示改为中文。
- 改进大型递归订单的规划准备与等待调度：复用规划阶段已有的库存映射；材料增加时按来源唤醒对应的阻塞步骤，已就绪步骤不再继续参与唤醒检查；单次操作找到可用机器后不再探测其他候选。
- 修复 Farmer's Delight 水面团配方的预览与缓存执行：静态结果为空时改用专用配方处理器解析实际装配产物，避免计划确认后被误取消。

## 机器与终端兼容

- **Forbidden & Arcanus 炽炉**：同一批原料可按容量分摊到两个空闲输入通道，按共享输出空间限制预载量；投料失败、取消和收取按本批实际物料处理，避免双通道重复备料或提前结束批次。
- **通用输入预载**：支持同一种材料分配到多个物理槽位，容量较小的通道放不下时由其他通道承担余量，不再把每个槽位都当成一份完整需求。
- **Farming for Blockheads 市场**：大额兑换按整批真实成本和支付物品规划，保留材料 NBT、存储选择及机器状态；确认执行复用已检查的兑换图，修复快速兑换绕过绑定或重复追加终端步骤的问题。
- **Wizards Reborn**：秘蕴迭代器中具有固定物品产出的配方可作为递归中间步骤，逐级附魔类配方仍按实际运行状态处理。
- **Better Summoning Rituals**：按整批需求扣除祭坛已有库存，催化剂只补一份；从终端发起时可选择可用的已绑定祭坛，执行时不再将整批缺料重复乘以次数，材料齐备的祭坛也能完成准备。功能仍只负责备料，仪式启动与世界产物收取由玩家处理。
- **Iron's Spells 'n Spellbooks**：按具体配方区分卷轴撰写台、奥术铁砧和炼金锅，修复绑定类型与实际执行机器不一致的问题。
- **Bosses' Delight 灵魂烹饪锅**：校验材料与实际输入槽位，并将碗等成品容器放入专用槽位，避免容器被当作普通食材处理。
- **Aetherworks 天华砧**：自动锤炼前刷新原生锻造炉状态，修复使用过期能量标记而跳过原生余烬消耗的问题。
- **Project MMO**：回收输入按物品 ID 匹配，带损伤、附魔、命名及其他 NBT 的物品可正常参与。
- **RS 终端**：虚拟铁砧领取结果时调用完整原生槽位回调，并在玩家位置播放音效；递归合成写回物品、流体时及时记录变化时间，便于按时间排序找到产物与退料。

## 万界归墟盘

- 模组更新导致物品、流体的 NBT 或能力数据恢复后身份改变时，隔离受影响条目，保留原始数据、数量和容量占用，其余正常库存继续可用。
- 加载时先校验原始数据，再用副本尝试恢复，避免反序列化改写待校验的身份；环境恢复后可重新尝试读取隔离条目。
- 提示与日志区分资源缺失、身份变化和数据结构损坏，并记录对应资源、槽位及变化字段，便于排查。

## 等级费用

- 随身携带或在当前可访问的共振磁盘中持有经验杖时，原版附魔、原版及 RS 虚拟铁砧按最低所需等级折算经验点费用，避免玩家等级越高，同一操作消耗的经验点越多；无需开启经验杖自动模式。
- 持有可访问经验杖时，铁砧仅重命名的费用固定为 1 级，并允许执行原先显示“过于昂贵”的修复操作；未持杖时保留原生费用规则。
- 对 Tetra、Enchanting Infuser、Waystones、两类祛魔台及暮色森林拆解台的已知等级扣费提供对应处理，并尊重 Forge 等级事件的取消和调整。
- 安装独立的 Tax Free Levels 时停用 RSI 的对应处理，避免重复接管；未安装的可选模组会跳过加载。

## 界面与提示框

- 为共振存储盘、BD 共振网络发生器、万界归墟盘、共振经验杖、点餐终端、共振魔力池、共振魔源罐及各类次元升级加入对应主题的提示框底板、图案与文字效果。
- 统一特殊物品的简略说明和 Shift 展开说明，补充存取、绑定、补货及使用指南；保留已有状态、完整数量与其他模组附加内容，未绑定、停用和异常状态使用醒目提示。
- 重做虚空升级规则界面，调整搜索、分类、候选与规则列表、滚动条、空列表提示和匹配复选框；已添加条目显示标记，规则使用独立删除按钮，名称规则可直接由搜索文字生成。
- 界面重建保留搜索内容，长名称省略显示并提供悬浮提示，滚动只在对应列表区域生效。
- 修复 Obscure Tooltips、Modern UI 圆角提示框覆盖 RSI 主题底板的问题。新增 `tooltips.customBackgrounds`、`tooltips.obscureTooltipsCompat`、`tooltips.modernUiCompat` 开关，默认开启，可在游戏内编辑，重新加载配置后生效；兼容处理只作用于使用 RSI 底板的物品。

## 开发者 API

- 新增 Machine GUI API，为原生交互存在副作用的方块注册优先远程菜单；新增 Storage API，提供玩家授权网络解析、定向快照、精确数量查询、工具检查和物品提取。
- 统一公共 API、机器端口与内部执行的产物声明，明确必出下限、最大数量、动态身份、固定次数与目标数量两种完成规则；增加概率目标未达成的诊断原因。
- 合并整理公共 API 接入指南，集中说明 API 版本、接入边界、机器与配方执行约定。

## 升级提醒

- 多人游戏请同步更新客户端与服务端，使用相同版本的 RSI。
- 点餐功能已内置；从旧 `rsfoodorder` 附属迁移时，终端物品与已吃记录由兼容逻辑处理。
- Goety 女巫坩埚界面可通过 `integrations.enableGoetyCauldron` 单独关闭；Goety 自身新增的原生坩埚配方仍由 Goety 处理。
- 发布文件名：`rs_integration-1.5.3.jar`。
