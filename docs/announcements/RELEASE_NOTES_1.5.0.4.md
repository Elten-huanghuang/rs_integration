# RS Integration 1.5.0.4 更新公告

- 更新日期：2026 年 10 月 8 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 上一版本：1.5.0.3

本次更新新增血肉祭坛兼容，完善铁魔法炼金锅的原生配方与药水流体处理，并修复统一盘备份、混合终端排序和祭坛网络识别问题。

## 新增与兼容

- 新增 Modrinth 版本更新提醒，自动检查匹配当前 Minecraft 版本的 Forge 正式版和 beta 版，并提供 Modrinth 下载入口；可在客户端配置 `updates.enabled` 中关闭，不自动下载模组。
- 新增克苏鲁生物（Cthulhu Creatures）血肉祭坛兼容，支持机器绑定、远程界面、递归合成、批量投料和多祭坛并行，并按配方实际数量计算材料消耗。
- 完善铁魔法（Iron's Spells 'n Spellbooks）炼金锅兼容，支持原生酿造与装瓶配方，以及药水、喷溅药水、滞留药水的流体酿造与装瓶；酿造遵循原模组的配置开关。
- 补充炼金锅原生配方的 JEI / EMI 合成入口，并支持在混合终端用玻璃瓶提取药水流体。

## 问题修复

- 修复混合终端“按 ID 排序”与 RS 原生排序规则不一致的问题；升序、降序均保持物品与流体分组，仅调整组内顺序。
- 修复生存模式背包塞满后，从虚拟切石机、锻造台和铁砧输入槽 Shift 快捷取出物品导致界面卡死、连接超时的问题；空间不足时停止转移并保留原槽物品，有部分空间时仅取出能够放入背包的数量。
- 修复虚拟工作站结果槽连续 Shift 领取时未重新检查领取条件的问题，避免铁砧经验不足后继续领取和消耗材料。
- 修复更多熔炉安装工厂升级后，低等级工厂被按六通道投料，导致材料进入未启用槽位、合成任务卡住的问题；现在按熔炉实际等级使用两格、四格或六格加工通道，并按实际容量分批投料。
- 修复终端绑定磁盘驱动器等通过代理提供网络节点的 RS 方块时，祭坛无法正确解析存储网络的问题。
- 修复车万女仆祭坛的绑定被原生或脚本配方目录限制的问题。
- 修复配方安全检查因反射解析无关方法而触发客户端专用类加载的问题，避免专用服务器上的相关类加载错误。
- 修复统一盘备份期间数据文件不一致的问题，增加 Simple Backups 兼容，在备份期间固定磁盘检查点，避免备份混入不同保存时刻的数据。


## 升级说明

- 多人游戏请同步更新客户端与服务端，使用相同版本的 RSI。
- 血肉祭坛兼容默认启用，可通过 `enableCthulhuCreatures` 配置项关闭。
- 更新检测默认开启；在 `config/rs_integration/client.toml` 中将 `[updates]` 下的 `enabled` 设为 `false` 即可关闭。
- 发布文件名：`rs_integration-1.5.0.4.jar`。
