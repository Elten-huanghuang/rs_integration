# RS Integration 1.6.1 更新公告

- 公告更新日期：2026 年 11 月 21 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 对比版本：1.6.0.1

1.6.1 优化了大型递归合成、缺料重算和机器产物回收，新增多种炉具与锅具联动。Relics 技能和 Alex's Mobs 嬗变台现在都支持按住空格连续操作。

## 新功能与物品

- **Relics 遗物**：在技能详情页按空格重掷，按住可连续重掷。每次仍按原版规则扣除经验，等属性和经验同步后才会继续。达到五星、经验不足或无法继续时自动停止。
- **Alex's Mobs 嬗变台**：按住空格连续选择第一个候选执行嬗变。三个候选中任一个与 JEI 或 EMI 收藏的物品及 NBT 匹配时，自动停止并保留当前候选。
- **精妙背包磁铁升级**：普通、高级和次元磁铁默认可采集范围内符合过滤规则的原版龙蛋，仍遵循玩家的方块破坏权限。可通过 `enableMagnetDragonEgg` 关闭。
- **共振磁盘**：原版无限弓可识别磁盘里的普通箭。背包没有可用箭矢时，也能使用磁盘中的普通箭满足无限附魔的弹药条件，射击时不会扣除它。
- **勇者章节·九剑九意**的剑数和额外伤害现在共用 `nineSwordMaxCount` 上限，默认合计最多 9 把拔刀剑。优先计入快捷栏，再用共振盘里的拔刀剑补足名额，额外伤害按计入的拔刀剑攻击力之和计算。
- **塔罗牌（Tarot Cards 1.7.0）**支持从共振盘触发被动效果。允许普通背包生效时，盘内已启用的散牌也会生效。开启牌组效果后，盘内牌组中的已启用卡牌也能生效。要求佩戴在饰品栏时，共振盘不提供这些效果。

## 材料与执行确认

- 修复材料表和悬浮提示把未确认来源的原料误标成「已安排补做」的问题。库存、缺口和未确认来源分开显示。
- 补料后重算会读取当前库存，不复用旧的失败预览。新结果会先在原页面显示，只有再次点「确认执行」才会下单。补料、重算和等待回包都不会自动执行。
- 对缺料旧预览的执行请求，服务端会明确提示重新规划，不再统一报「计划已失效或状态变动」。实际下单仍会复验材料、存储网络和机器状态。

## 大型规划与执行

- 减少深层、宽分支和多模组配方的重复搜索与回溯。固定配方分支可在后台规划，再由服务端分批验证并合入计划，减轻生成计划时的卡顿。
- 规划超时会保留只读配方树和已结算材料。草稿不是完整订单，不能执行；未算到的材料也不会按零缺口处理。
- 统一递归任务的依赖调度，减少合成启动、运行中取料和并行任务调度的开销。执行中需要补料时，规划可跨 tick 继续，并按当前任务剩余需求核对补料数量。
- 改善无存储网络时的工作台催化剂规划，统一空 NBT 与无标签物品的运行时匹配。万能溶剂之经的特殊配方已从递归合成候选中排除。

## 机器与模组联动

- **超越维度**：次元炉支持批量加工和自动收取产物，并检查炉子槽位、过滤、自动弹出和燃料设置。
- **农夫乐事及附属**：修复点菜终端的动态配料与填充物校验、多层蒸笼自动合成、砧板执行报错和工具耐久复用。并行烹饪会跳过缺少热源的锅。
- **魔法食事**：奥术烹饪锅可按配方选择对应流派的卷轴，烹饪完成后回收卷轴。火焰卷轴可以供热，其他流派仍需锅下热源。
- **诡厄乐事**：支持诅咒金属锅、神灵金属锅的专属配方和亡灵注入后的烹饪。按原模组规则校验锅具、注入状态和灵魂能量。
- **Goety**：兼容心灵之庭的仪式结构检查。未手动锁定材料时，确认合成会按当前库存匹配材料变体。仅有 JEI 占位产物的仪式交由玩家确认。
- **产物收取与取消回收**：修复营火、煎锅、Botania 植物酿造台、Eidolon 仪式、Malum 精魂坩埚、车万女仆祭坛和 Wizards Reborn 水晶等联动的收取与回收问题。修复部分祭坛或水晶联动在收取产物时误扣玩家物品的问题。
- **其他兼容修复**：Apotheosis 宝石切割可混用符合配方、NBT 不同的消耗材料，刷怪笼升级预览刷新后保留所选升级。Tetra 工作台补齐蓝图直接声明的改装材料。修复专用服务端的 FTB 任务提交和 Malum 祭坛的精魂匹配。

## 配方界面与诊断

- 流体容器配方分批扫描和注册，减少客户端加载时的卡顿。注册完成后自动刷新已打开的 JEI 配方页。
- JEI 和 EMI 的远程合成提示统一使用绑定机器的原生翻译。例如暗灵工作台会显示「通过暗灵工作台远程合成」。
- 远程机器交互按实际菜单切换判断是否成功。机器绑定信息转换失败后，可在后续刷新时重试同步。
- 汇总配方目录采集的同类超时告警，保留次数与最慢项，减少日志刷屏。
- 增加计划界面注释、合成成功事件与缺货取物回退接口。详见 [开发者 API 文档](../api/README.md)。
