# RS Integration 1.6.0 更新公告

- 更新日期：2026 年 11 月 13 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 上一版本：1.5.3
- 公告范围：以 11 月 2 日发布的 [1.5.3 更新公告](RELEASE_NOTES_1.5.3.md)为基线，汇总此后的全部更新，包含原“1.5.3 后续更新公告”的内容；相同功能的多次调整合并说明。

本次更新重点重构了**递归合成树界面**，完善**合成监控与步骤等待关系**，优化**大型订单规划和多任务执行**，并集中修复材料取用、催化剂复用、流体交付、点餐队列及归墟盘备份等问题。

## 递归合成树界面重构

- 重新设计递归计划界面：固定标题与材料摘要，主区域可切换**合成树 / 完整材料列表**，右侧抽屉集中展示**步骤、缺料、条件提示**，底部保留数量与执行选项。
- 步骤节点展示名称、数量和机器，原材料使用紧凑物品槽；优化节点、连线、选中高亮与折叠状态，移除旧的独立步骤卡片 / 网格视图，保留 JEI 原生配方布局预览。
- 点击步骤后，直接在详情卡片下方展示**当前步骤的制作配方**；通过“**切换配方**”进入独立候选页。材料种类也使用独立候选页，保留搜索、自动选材、指定变体、禁用 / 恢复递归制作、清除默认配方等操作；候选支持键盘选择。
- 顶部搜索支持名称、物品 ID 和拼音，输入后显示下拉候选；同名节点可根据图标、数量、上级材料和位置编号区分。选中后自动展开祖先节点、居中并放大，也可查找已折叠的节点。
- 完整材料列表支持搜索、仅看缺料、定位和收藏；缺料卡片分别显示需求、库存与净缺口，支持单项或全部收藏。修复通用物品名称识别和错误匹配，无法确认身份的提示保留原文，不再误关联到其他材料。
- 合并重复的缺料与条件入口，点击标题中的“**缺少 N 种材料**”或“**N 条条件提示**”直接展开对应列表。条件提示完整换行，保留机器、研究、并行等诊断；点击条目只定位节点，保留当前看板与滚动位置。
- “重新检查路线”显示运算阶段、耗时及完成 / 失败提示；重算期间保留旧树，切换失败时保留之前可用的选择，并可查看原因后重试。库存更新只刷新材料状态，搜索、导航和查看侧栏不触发重新规划。
- 完善右下缩略导航、适配整树、步骤列表与上 / 下一步定位；保留平移、缩放、中键查看 JEI、机器自动 / 优先 / 独占选择、次数快捷项、严格 / 只准备材料、产物去向和存储网络选择，以及余烬专属选项。
- 适配窄窗口与不同 GUI 缩放，修复 **3× 缩放**下材料摘要、余产物、底部按钮的错位和溢出，以及树中物品穿透缩略导航的问题。
- 优化绘制批次，裁剪屏幕外节点与连线，缓存缩略导航投影和条件列表换行，仅绘制可见列表行；进入配方候选页时再加载候选预览，减少打开和持续浏览时的重复开销。
- 新增独立客户端主题文件 **`config/rs_integration/plan_ui.toml`**，可调整背景、节点、连线、文字、缺料 / 条件颜色、面板尺寸、节点名称和缩略导航大小；已有玩家配色不会被更新强制覆盖。参见[配置说明](../config/plan-ui.md)与[主题示例](../config/plan-ui.example.toml)。

## 合成监控、多计划与机器管理

- **运行中的 RSI 合成任务接入 RS 原生合成监控**，统一展示任务、步骤、材料状态和实际产出；完善直接打开监控、返回同一网络终端和跨维度终端的导航与同步。
- 监控器补充**步骤之间的等待关系**：可查看正在等待的材料、来源步骤、受影响的下游与关联机器，点击来源可继续定位并返回；外部缺料与尚未同步完整的等待明细分别提示。
- 增加等待原因汇总、关注筛选、机器位置和服务端执行计时，调整任务栏、搜索框及详情布局。支持可靠计时的机器显示本轮加工进度，未知进度保留明确提示，实际完成次数继续独立更新。
- 后台运算完成的待确认计划会保留在多计划列表，支持切换、取消计算和移除待确认计划；修改同一计划数量时只保留最新结果，复用有效路线与预览，避免重复请求。
- 计划页可“隐藏计划 / 显示计划”，并记住客户端设置；隐藏后后台计算与正在执行的合成继续运行。精简常驻 HUD 和计划提示条，保留目标数量、进度、流体单位、运算进度及当前快捷键。
- 修复点击 JEI 加号后进度提示不出现、界面仍停留在 JEI，必须关闭后再按快捷键才能查看的问题；修复后台计划聊天链接无法执行客户端命令的问题。
- 重绘绑定机器界面，统一底板、卡片、导航、滚动和返回行为；保留搜索、收藏、解绑、右键单台拉黑和拖动框选。新增**机器自定义名称**，支持编辑、搜索、权限检查与保存。
- 计划列表、合成监控和共用控件可通过客户端 `client.toml` 的 **`[craftingUi]`** 调整配色，也可在游戏内客户端配置界面修改并应用；支持不同材料状态的整格底色。参见[配色示例](../config/crafting-ui.example.toml)。

## 大型递归规划与路线可靠性

- 优化长链配方、深层依赖、大批量需求及多个并发规划请求；使用显式栈、需求聚合与分段续算，减少重复遍历和集中占用主线程。各请求保留独立的搜索进度与取消状态。
- 优化多个分支的共享供料、副产物复用、分批生产和依赖顺序，修复可行路线因整批需求、标签选材循环或转换环误判而无法规划的问题；修正大数量溢出及部分配方生产路线遗漏。
- 复用有效的规划路线、配方浏览器预览和库存结果，优化库存足够时的分支截断；对已经确认的目录缺口限制重复试探，并及时切换解析路径。
- 修复“仅用库存”等选择下缺口重复统计；刷新树时保留显式中间配方选择，确认计划时按正确的物品身份验证，并保留服务端原始 NBT 与能力数据，减少确认失败或路线被重置。
- 合成预览按相关物品 / 流体库存变化增量更新，保留已选路线；完善断线重连、消息顺序和执行前复验，减少管道库存短暂波动导致计划被取消的情况。
- 完善规划时间片、库存订阅预算、执行批量等配置与示例，便于整合包根据规模调整。预览反映当前库存，实际执行仍需重新验证材料。

## 执行、取料与产物结算

- 统一图计划与顺序补做的批量执行，按数量汇总材料、在途数量和待派发需求，减少大订单逐次展开；默认跟随机器自身批量能力，并保留可配置上限。
- 完善同网络多个任务的材料分配，修复运行中相互抢料的问题，同时保留可用资源允许的多任务并行；物品与流体采用一致的任务准入和交付规则，减少绕过任务分配直接取料的情况。
- 保留存储网络物品的原始 NBT，修复取料身份漂移、混合 NBT 材料分配和并行完成后的执行状态校验；修复继承输入状态的并行产物被误判为未完成，以及复制 / 自增配方的分阶段执行问题。
- 完善缺料唤醒、重试退避与超时判断，按实际工作进度刷新超时；减少被动机器的无效轮询，修正原版机器燃料判断，并利用酿造台倒计时安排检查。无效请求或转移结果不明时停止重复执行。
- 完善取料、机器部分接收、取消和失败后的材料对账与退款，按实际成功转移和恢复的数量结算；修复退款重放及流体转移过程中的重复处理，保留异常记录供管理员诊断。
- 背包与当前 RS / BD 网络都无法接收合成物品时，剩余物品会按堆叠上限掉落在玩家脚边并保留 NBT，避免被合成捕获区再次收走；掉落失败时只暂存尚未掉落的余量并提示领取。

## 机器、配方与模组兼容

- **Embers 余烬炼金**：修复元素象征的催化剂识别、跨批次复用、交接和回收，解决相关炼金卡料问题。
- **Malum 灵灾**：修复相邻祭坛物品台扫描干扰与卡顿、坩埚增产后剩余精魂未返还、虚空恩惠虚拟转化无法启动并超时，以及配方产物继承输入 NBT 的问题。
- **Goety 及其他带状态催化剂的配方**：修复催化剂 NBT 变化、配方空槽和重复原料合并时的返还映射，避免产物误判和无法继续复用；修复反射检查缺失类型引发的 JEI 崩溃。
- **Farmer's Delight 农夫乐事**：修正面团水桶类材料的标签识别及催化剂角色，按配方规则复用和返还。
- **Youkai's Homecoming 妖怪归家**：统一料理板预览与执行的材料采集，补全成品食物基底，例如加工加州卷时正确计入原有加州卷。
- **原版锻造 / 匠魂等展示配方**：修复静态锻造产物的默认耐久标签误将底材限定为全新状态；兼容不提供序列化器的 JEI 展示配方分类。
- **JEI / EMI**：修复部分新版 JEI 界面消失、合成与机器按钮无响应的问题，兼容新旧版本事件处理；完善规划与机器界面的面板避让，以及配方浏览器预览复用。
- **FTB Quests**：修复任务提交预览响应、混合取料和 JEI 配方同步刷新。
- 修复机器绑定远程权限检查和重复点击误解绑；补充精妙存储磁铁升级兼容，并修复未安装 RS 时监控导航自动订阅引发的启动崩溃。
- 完善归墟 / 共振盘、点餐终端等物品的主题提示框纹饰与屏幕边缘适配，保留字体及扩展提示兼容。

## 点餐终端

- 修复大型食物目录分包同步不完整，导致部分食物搜不到或刷新失效的问题；优化搜索索引、食物候选缓存和可用性检查，检查可跨 tick 继续，连续刷新请求合并处理。
- “**全部下单**”保留完整候选队列，分批预检与提交；达到并发上限时等待已有订单释放名额，再按最新库存继续，不再直接截掉剩余食物。
- 依据实际队列进展处理等待与超时，释放不再使用的检查会话和预览计划，避免长时间运行的正常订单被总队列时长误判失败。
- 列表状态刷新时保留选中的食物与滚动位置。

## 万界归墟盘与备份

- 修复统一盘备份缺页；FTB Backups 2 的 ZIP 和目录备份在收集世界文件前建立一致的数据检查点。
- 补齐增量备份对魔力资源文件和尚未迁移的旧版灵魂数据的覆盖。
- 修复 FTB 备份兼容注入导致的启动崩溃。

## 升级与发布说明

- 正式发布版本号为 **1.6.0**，文件名为 **`rs_integration-1.6.0.jar`**。替换旧版 RSI JAR 后重启游戏或服务器，客户端与服务端使用相同版本。
- 保留已有配置；递归树独立主题与监控器配色分别配置，更新不会强制重置玩家的调色。
- 完善发布包完整性校验，修复重复构建或中间文件丢失后可能遗漏运行所需映射的问题；Windows 构建优先使用项目本地完整 JDK 17，并限制本地依赖映射的内存占用与并发。
- 补充配方分析、合成材料对账及相关回归验证工具，完善真实模组兼容测试依赖准备。
