# RS Integration 1.5.3 后续更新公告

- 更新日期：2026 年 11 月 11 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 公告范围：以 11 月 2 日发布的 [1.5.3 更新公告](RELEASE_NOTES_1.5.3.md)为基线，汇总此后的功能改进与问题修复。

这轮更新重点优化了**大型递归合成的规划与执行**，完善**多计划管理**，将运行中的 RSI 任务接入 **RS 原生合成监控**，并修复多种机器的卡料、催化剂返还和备份问题。

## 大订单与合成稳定性

- 优化长链配方、大批量需求和多个规划请求的处理，减少重复计算与主线程卡顿；复杂规划可分段继续计算，取消请求也会独立处理。
- 修复大数量计算溢出、标签选材循环和部分配方路线识别不完整的问题，改善长链规划的可靠性。
- 优化批量投料与材料统计，减少大型订单逐次展开的开销；默认跟随机器自身的批量能力，并保留可配置上限。
- 合成预览按相关物品和流体的库存变化更新，保留已选择的配方路线，减少管道库存短暂波动导致计划被取消的情况。
- 按实际工作进度判断超时，减少被动机器的重复检查；修正原版机器的燃料判断，并优化酿造台的等待检查。
- 完善取消订单和机器部分接收材料后的退料结算，按实际恢复的材料处理。

## 多计划、合成监控与界面

- 完善多计划列表：后台计算完成的待确认计划会保留，支持切换计划、取消计算和移除待确认计划；修改同一计划的数量时只保留最新结果。
- **运行中的 RSI 合成任务可在 RS 原生合成监控中查看**，统一展示任务、步骤、材料状态和实际产出。
- 完善直接打开合成监控、返回同一网络终端及跨维度终端的界面同步与导航。
- 计划页新增**“隐藏计划 / 显示计划”按钮**，可收起侧边计划提示，并记住客户端设置；隐藏后，后台计算和正在执行的合成仍会继续。
- 重绘绑定机器界面，统一灰紫底板、像素边框、白色卡片和顶部导航，适配不同窗口宽度；保留搜索、收藏、解绑、右键单台拉黑和拖动框选，并修正返回上一页的行为。
- 精简常驻合成 HUD，保留目标数量、进度、流体单位与当前快捷键提示。

## 机器与模组兼容修复

- **Embers 余烬炼金**：修复元素象征的催化剂识别、跨批次复用与回收，解决相关炼金卡料问题。
- **Malum**：修复相邻祭坛物品台扫描相互干扰和卡顿；修复坩埚增产后剩余精魂未正确返还；修复虚空恩惠虚拟转化无法启动、等待后超时的问题。
- **Goety 等使用带状态催化剂的配方**：修复催化剂 NBT 变化、配方空槽和重复原料合并时的返还位置错误，避免误判产物缺失或无法继续复用。
- **JEI**：修复部分新版环境下界面消失，以及合成、机器按钮点击无响应的问题，兼容新旧版本的交互处理。
- 修复机器绑定的远程权限检查，以及重复点击可能引发的误解绑；补充精妙存储磁铁升级的兼容修复。

## 点餐终端

- 修复大型食物目录同步不完整，导致部分食物搜不到或刷新失效的问题。
- 优化食物可用性检查、连续刷新和搜索索引，减少大目录处理时的集中开销。
- 状态刷新时保留当前选中的食物和列表滚动位置。

## 万界归墟盘与备份

- 修复统一盘备份缺页问题；FTB Backups 2 的 ZIP 和目录备份会在收集世界文件前建立一致的数据检查点。
- 补齐增量备份对魔力资源文件及尚未迁移的旧版灵魂数据的覆盖。
- 修复 FTB 备份兼容注入导致的启动崩溃。

## 升级说明

- 替换旧版 RSI JAR 后重启游戏或服务器。
- 完善发布包完整性检查，修复重复构建时可能遗漏运行所需映射的问题。
- **本轮构建的版本号仍为 1.5.3**。联机时请让客户端与服务端使用同一构建，避免仅核对版本号而混用不同日期的文件。
- 发布文件名：`rs_integration-1.5.3.jar`。
