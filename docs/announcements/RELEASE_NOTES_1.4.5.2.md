# RS Integration 1.4.5.2 更新公告

本次更新新增 Summoning Rituals 召唤祭坛的批量合成支持，并修复了 FTB Quests、Goety、炽炉等模组联动中的问题。

## 新增内容

- 支持 RS 识别 Summoning Rituals 的祭坛配方，并通过绑定的召唤祭坛执行批量合成。
- 召唤祭坛配方会正确区分催化剂与消耗材料，避免两者混用导致配方无法执行。

## 修复与改进

- 修复炽炉批量合成无法启动的问题。
- 修复 Goety 仪式合成中的灵魂能量计算。
- 修复 Goety 暗黑铁砧被错误识别为原版铁砧的问题。
- 修复 FTB Quests 一键确认可能提前提交任务的问题。
- 改进 FTB Quests 对奖励物品和 Curios 饰品的识别；领取奖励后会重新检查玩家持有的物品。
- 新增配置项，可分别控制 FTB Quests 侧边栏中的批量确认和存储扫描按钮。
- 修复农夫乐事砧板刀具被重复加入递归合成的问题。
- 兼容了历史记录mod

## 升级说明

- 版本号：`1.4.5.2`
- Minecraft：`1.20.1`
- 多人游戏中，客户端和服务端请使用相同版本的 RSI。
