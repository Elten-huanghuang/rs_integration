# RS Integration 1.3.4 更新公告

**发布日期：** 2026 年 8 月 17 日

本公告收录 `1.3.3` 发布提交 `8e38369` 之后的全部改动。`1.3.3` 已公布的内容不再重复。

## 修复

### 递归合成与材料结算

- 修复 Goety、Wizards Reborn、锻造等运行时 NBT 配方的产物结算。成品已经进入 RS 或玩家背包时，不再错误提示 `output shortage`。
- 修复图节点与执行步骤之间的产物累计和身份跟踪，避免动态产物、同类多产物及运行时变体丢失对应关系。
- 修复 FTB Quests 在团队数据锁定、任务拒绝或仅接受部分物品时的结算，未被接受的材料会正确退款。
- 修复取消、超时、延迟启动和委托拒绝时的材料所有权与清理，避免重复退款、吞料或遗留预留材料。
- 修复 KubeJS 催化剂、复制模板、返还容器及其他剩余物的批量计算。返还物会与真实工作台槽位对齐；合成 64 次时，可复用材料不会错误展开成 64 份需求，带 NBT、耐久或能量的催化剂会按每次操作连续更新状态。
- 修复 Ars Nouveau 附魔装置延迟启动时重复抽取或退款的问题；机器真正接受配方后才会确认启动。
- 修复 Iron's Spells 'n Spellbooks 卷轴撰写台对远程菜单状态的错误依赖，改为按机器实际输出和目标卷轴数据验证完成。
- 修复 Goety 动态附魔仪式、祭坛委托和图执行之间的产物发布与回收，成品已交付时不再误报失败。
- 修复合成链无进展计时。节点完成、机器推进或实际产物发布后会重置计时，长耗时机器不再沿用最初时间随机超时。
- 异步计划返回后会重新检查玩家、配方版本、库存、RS 网络和机器绑定；过期计划不会直接执行。

### 配方规划与性能

- 重构纯需求树检查，分别记录普通缺料、特殊依赖无法投影和节点上限，不再因普通缺料无条件回退到主线程 typed 解析器。
- 大型标签改为有界候选探测，找到可表达路线后停止遍历全部压缩、解压和容器变体。
- 剪除没有库存支撑的反向解压路线、压缩/解压闭环和无收益材料变体，同时保留精确产物及数量确有增长的路线。
- 修复 Prefab 高级农场等配方在大量木材、木板、木箱和砖块变体中反复搜索并超时的问题。
- 材料不足时仍会生成可读的部分配方树，展示已确定的合成链和最终缺少的基础材料，不再只显示笼统超时。
- 修复配方树根节点的替代配方切换。手动选择目标配方后，后续递归不会再被库存物品或默认路线替换，CraftTweaker、KubeJS 等脚本配方也会保留用户选择。
- 配方计划缓存增加状态重验，仅在库存、网络、机器绑定和配方版本仍一致时复用。
- 默认规划预算调整为后台纯规划 `1500 ms`、主线程 typed 预览 `500 ms`、执行解析 `2000 ms`；简单配方仍会立即返回。

### 机器执行与路由

- 修复 Avaritia 各级工作台、Botania 魔力池及其他机器特定配方的分类，避免因配方 ID 或类名前缀相近而投放到错误机器。
- Wizards Reborn 奥术迭代器会在抽取材料前检查基座数量；结构不足时显示已有/所需数量并切换候选机器。
- Goety 多祭坛改为逐台验证前置条件。一台祭坛条件不足时，其他满足条件的已绑定祭坛仍可执行。
- Iron Furnaces 工厂和彩虹熔炉会按真实输入通道和物理容量拆分批次，并在多台机器之间均衡任务，不再退化为一次烧制一个。
- Botania 魔力池会在多台已绑定池子间平均分配任务，每台池子单个物理批次最多处理 128 次灌注；白雏菊也会报告结构的真实并发容量。
- 原版烧炼包装器和其他通用批量机器会向图调度报告真实容量，不再无故逐个执行。
- 泛型委托增加明确的图执行能力契约，不支持图执行的机器会在扣料前回退或拒绝，避免启动后出现 `delegate rejected graph dispatch`。
- 修复熔炉、Iron Furnaces、Embers 炼金台等机器在上一轮结束后残留准备状态或资源占用，导致下一轮无法启动的问题。
- 修复关闭远程 GUI、机器消失、并行任务切换或合成链中止时未释放菜单上下文、捕获区和准备资源的问题。
- Ars Nouveau 动态配方分类更加严格，不支持自动执行的运行时配方不会误入普通递归图。

### 界面、同步与稳定性

- 修复机器收藏、取消绑定和机器失效后管理中心列表不及时刷新的问题。
- 修复配方树图标和目标识别：Goety 仪式节点会显示黑暗祭坛图标，根节点会按树的真实根配方判断切换入口。
- 修复搜索历史浮层打开时仍渲染底层 RS 物品提示的问题，避免两个 tooltip 相互遮挡。
- 改进失败原因与日志分类，普通缺料、规划超时、节点上限、候选机器不满足和实际产物缺失会分别报告。
- 不支持的原生配方会按类型、数量和少量样例汇总记录；工作台配方不再反复探测不存在的零参数 `getRemainingItems()`，减少启动阶段大量重复警告。
- 可选模组缺失或版本字段变化时使用能力探测和安全降级，减少跨版本硬链接导致的启动失败。
- 扩充 Prefab 木材链、宽标签、动态 NBT、Goety 图腾、机器绑定、远程菜单、并发调度及退款路径测试。

## 新增

### 新增支持

- **MythicBotany Mana Infuser（精灵凝聚板）**：支持原生及 KubeJS 自定义配方的递归合成，自动验证多方块结构、材料、魔力和产物，并完成批量投入、捕获、取消与退款。
- **Improved Botania Pools**：支持直接绑定 Alfheim、Asgard、Muspelheim 和 Nilfheim 四种扩展魔力池，复用 Botania 灌注、催化器、批处理和负载均衡逻辑。
- **Ars Nouveau 抄写台**：支持 `ars_nouveau:glyph` 原生及同类型数据包魔符配方；抄写台左右两半都可绑定并归一到同一台机器。计划预览会显示单次经验需求和玩家现有经验；取消或失败时分别返还材料和已扣经验。
- **Ars Nouveau 附魔装置附魔书**：附魔配方现在具有可索引的确定输入与产物，可递归识别高等级附魔书路线，例如使用两个效率 III 附魔书制作效率 IV。
- **Goety 阴咒注入器与 Goety Awaken 魂咒融注器**：三类注入器共享诅咒注入配方入口，并按原生能力筛选普通或 Grim 配方；增强机器支持 64 个配方槽，魂咒融注器的装备与图腾修复槽不会被误占用或清理。
- **Immortaler's Delight 新旧版本**：同时兼容新旧 Enchantal Cooler（怨泉）的类名、字段、燃料、产物、机器绑定和 JEI 入口。
- **Immortaler's Delight 怨泉浸泡**：新增独立配方识别、JEI 合成按钮和递归执行入口，浸泡材料、流体与产物会按新版原生结构处理。
- **Gensokyo Delight 0.5.0 与 Youkai's Homecoming**：兼容新 `inputFluid` / `outputFluid` 和旧水量字段。`white_wine`、`red_wine` 等纯液体发酵不再显示“空气”；`champagne`、`burgundy`、`van_allen` 等固液混合发酵会同时规划固体和葡萄汁，完成后回收空容器，取消时不会双倍退款。
- **共振磁盘怨泉资源**：支持 `immortalers_delight:hot_spring_bucket` 怨泉桶和 `hot_spring` 怨泉水，同时保留旧版流体、Lychee 虚拟配方和 NBT 兼容。
- **Placebo 系机器远程界面**：增加服务端 BlockEntity/Menu 快照，同步必要状态后再构造远程 GUI。
- **KubeJS 工作台扩展语义**：支持普通消耗、返还容器、可复用催化剂、复制模板、运行时输出及阶段限制，并兼容相同格式的数据包配方。需要配方阶段的内容会在预览和执行时检查玩家解锁状态，未解锁时会在扣料前拒绝。

### 新增功能

- **RS 搜索历史**：新增搜索历史浮层，按搜索模式保存最近记录，支持恢复、收藏、取消收藏、单条删除和清空；历史会持久化到客户端并自动处理损坏数据。
- **机器收藏**：机器管理中心新增独立星标交互，侧边栏可固定常用机器；收藏状态、顺序和数量上限按玩家保存并同步。
- **机器快捷解绑**：在机器管理中心按 `Ctrl` + 左键可直接取消绑定，列表立即同步刷新。
- **Goety 灵魂能量催化剂**：灵魂图腾、根之图腾及同类派生图腾可按灵魂能量复用；批量计划会分别显示祭坛能源总消耗、图腾总消耗、最高可用图腾能量和不足提示，不再为每次合成递归制作一只图腾，剩余能量与 NBT 会正确返还。
- **部分配方树展示**：复杂配方即使材料不足，也能查看已经解析出的步骤、缺少材料和可选择路线。
- **机器能力感知调度**：图调度会根据机器容量、可复用催化剂数量和候选结构分配并发任务，多台兼容机器可安全负载均衡。
- **远程状态同步基础设施**：新增搜索历史、机器收藏和远程菜单快照所需的网络数据包与客户端处理逻辑。

## 升级说明

- 模组版本升级为 `1.3.4`，发布文件为 `rs_integration-1.3.4.jar`。
- 网络协议从 `31` 升级到 `32`。客户端与服务端必须使用同一份 `1.3.4` JAR，旧版本会在连接阶段被拒绝。
- 服务端配置结构升级到版本 `6`。启动时会把旧默认的纯规划预算 `500 ms` 迁移为 `1500 ms`、typed 预览预算 `400 ms` 迁移为 `500 ms`，并把旧默认的计划缓存寿命 `500 ms` 迁移为 `30000 ms`；所有非默认自定义值都会保留。
- 执行解析预算仍为 `2000 ms`，无需删除配置文件或世界数据。
- 更新不会清除 RS 网络内容、共振磁盘、机器绑定、机器收藏或已有炼金编码缓存。
