# RS Integration 1.5.0.3 更新报告

- 更新日期：2026 年 10 月 6 日
- 适用环境：Minecraft 1.20.1 / Forge 47+
- 上一版本：1.5.0.2

本次更新集中修复部分玩家进服掉线的问题，并优化共振存储盘与递归合成配方索引，减少重复库存扫描、无效终端刷新和集中加载配方带来的服务器主线程负担。

## 问题修复

### 万界归墟盘导致部分玩家掉线

- 修复携带尚未初始化的万界归墟盘时，在异步背包更新环境中可能触发线程检查异常，导致玩家进服后掉线的问题。
- 磁盘初始化改为登记请求后由服务器主线程执行，避免在异步背包更新线程上创建磁盘数据或修改磁盘身份。
- 执行初始化前重新检查玩家在线状态和当前背包槽位，避免玩家移动、丢弃物品或重新连接后写入过期物品。
- 玩家退出和服务器停止时清理待处理请求。

### 混合终端无法取出最后一桶流体

- 修复网络恰好剩余 `1000 mB` 时，鼠标装桶操作无法取出最后一桶流体的问题。
- 装桶过程使用独立的流体副本，避免缓存清空库存条目后丢失流体身份并误触退款。
- 支持空鼠标从网络取桶、手持空桶和堆叠空桶；不足一桶时不消耗空桶或流体。

## 性能优化

### 共振存储盘查询与终端刷新

- 共振盘物品存在性与数量查询复用按内容版本维护的查询缓存，减少重复遍历库存、创建快照和复制物品数据。
- 减少公开库存快照中的重复物品复制；查询回调仍使用独立副本，防止外部查询修改盘内数据。
- 盘内物品状态变化后及时失效查询缓存，保证后续查询读取最新内容。
- 共振盘内部状态变化不再使普通 RS 库存缓存失效，减少无必要的终端全量重建和库存重扫。

### 递归合成配方索引

- 启动和重新加载配方时，配方采集改为按服务器 tick 分片推进，减少一次性扫描大量配方造成的长时间停顿。
- 世界、注册表和第三方配方读取保留在服务器主线程；采集后的数据整理和索引准备由后台完成。
- 主线程只发布已经完成且版本仍然有效的配方索引，丢弃重载或失效前的旧构建结果。
- 防止重复启动同一轮构建，并在后台整理尚未完成时直接返回，避免服务器主线程等待后台任务。

## 合成请求与提示

- 配方索引尚未就绪时，合成请求进入等待队列，并显示“配方索引仍在加载”的提示。
- 等待配方索引超过 30 秒的请求会被取消并提示重试，避免无限等待或稍后意外执行。
- `/reload` 后重新构建配方索引，避免继续使用过期配方。
- 补充对应的中文与英文提示。

## 测试修复与验证

- 修复铁魔法配方同步契约测试依赖固定方法修饰符的问题，保留“索引失效后重试、构建失败后不重复重试”的检查。
- 增加流体实时缓存变化下的边界回归测试，覆盖 `999 / 1000 / 1001 / 2000 mB` 和不同空桶操作。
- 全量自动化测试：2334 项，0 失败，4 项按环境条件跳过。
- 发布包已成功构建，`verifyReleaseJar` 对版本信息、必要资源和运行时映射的校验通过。
- `verifyNoForcedChunkLoads` 对强制区块加载约束的检查通过。
- 尚未在同一服务器环境下采集更新后的 Spark 报告，暂无 TPS 或 MSPT 提升幅度的对比数据。
