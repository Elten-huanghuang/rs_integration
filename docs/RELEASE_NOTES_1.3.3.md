# RS Integration 1.3.3 更新公告

**发布日期：** 2026 年 8 月 14 日

本版本包含从 `1.3.2` 到 `1.3.3` 的全部改动，重点完善递归合成的规划与回收安全、Iron's Spells 'n Spellbooks 及其附属兼容、跨模组机器路由，以及配方树和机器管理中心的交互。

## 递归合成与材料安全

1. 修复通用机器合成链使用不可变列表时无法继续执行的问题。
2. 完善容器、工具和可复用催化剂的剩余物回收，取消图合成时会归还已投入的可复用催化剂。
3. 修复并行批量合成错误重复占用催化剂，以及催化剂不足时可能出现的错误拆分和材料损失。
4. 保留升级材料、模板和其他带 NBT/状态物品的完整数据，避免递归合成把它们替换成无状态物品。
5. 修复基于槽位收集产物、Malum 状态型灌注产物捕获及图节点与执行步骤映射错误。
6. 修复合成实际成功但因产物统计不同步而提示失败的问题，并改进中止、退款和产物短缺判定。
7. 阻止可自我增殖或等价解压配方无限放大批次数量。
8. 递归规划改为优先使用 RS 库存，合并重复需求，并剪除解压回路、无库存容器变体和无收益转换路径。
9. 改进图执行与旧执行器之间的回退逻辑，减少 `delegate rejected graph dispatch`、规划超时和错误卡在“准备执行”的情况。
10. 完善原版酿造配方目录、药水容器识别和递归规划。
11. 修复明确选择附魔书生产路线后仍直接消耗已附魔工具的问题；强制分支现在只使用该分支新产出的物品，求知之书提取路线不会被库存中的匹配工具绕过。
12. 修复递归产物写入 RS 或玩家物品栏后材料缓存和已打开背包未立即同步的问题；求知之书等中间产物现在可以直接用于下一步合成，无需关闭并重开背包。

## Iron's Spells 与法术附属

1. 新增 Iron's Spells 'n Spellbooks 法术卷轴的递归合成。
2. 接入卷轴撰写台（Scroll Forge）和奥术铁砧（Arcane Anvil），支持制作、升级高级法术卷轴。
3. 同时兼容新旧版本的 Iron's Spells 配方结构，并支持动态配方、NBT 卷轴和附属模组注册的法术。
4. 根据目标卷轴实际稀有度选择正确墨水，修复稀有、史诗及卓越卷轴选错墨水的问题。
5. 支持 Refined Mod、T.O Magic 'n Extras、Peyro's Scythe、GTBC's Geomancy Plus 等使用 Iron's Spells 工作台体系的附属卷轴。
6. 新增 Apprentice Codex 的精华熏炉（Essence Smoker）和施法者工作台（Spellcaster Workbench）自动合成。
7. 新增 ISS CSW 法术锻炉及混合法术配方支持，包括以多个法术卷轴作为原料的配方。
8. 修复法术工作台绑定、机器界面返回、动态配方发现、附属卷轴输出验证和成功后误报失败的问题。
9. 防止自定义法术原料匹配器触发空指针或类型错误，并优化大量卷轴配方的递归规划性能。
10. Ars Nouveau 的附魔和护甲升级属于依赖具体 NBT 中心物品的动态配方，现不再被当作未知配方重复打印警告；正常自动合成行为不变。
11. Apprentice Codex 精华熏炉使用任意法术卷轴时，会优先消耗 RS/玩家库存中实际稀有度最低、再按法术等级最低的有效卷轴；没有库存时，递归规划也按相同成本顺序选择卷轴配方，普通卷轴不会再被传送术等更高稀有度卷轴抢先。
12. 调整自动合成的库存优先级：精妙背包中的附魔、已损耗或改名工具不再被宽泛配方当作普通材料自动消耗，避免误用常用装备；明确的严格 NBT 原料仍按配方要求处理。
13. 修复次元磁铁与植物魔法魔力灌注等世界物品机器冲突：磁铁扫描范围与自动合成捕获区重叠时会暂时跳过扫描，避免原料被拉走后合成链一直等待。
14. 植物魔法魔力灌注支持单池物理批处理和多池负载均衡，单次最多 1024 次；多个有效绑定池会同时领取均衡批次，每池每轮最多 128 次（例如 128 次配合 4 个池时每池 32 次）。相邻池使用互不重叠的池面产物捕获区，不再因安全冲突退化成单池串行；取消部分完成的批次时，只结算已实际产出的次数，其余材料正常退款。

## 机器与模组兼容

1. 物品栏中的 RS 网络连接器现在可用于附近机器范围扫描，不再要求必须手持或装备。
2. Sophisticated Storage 的 grouped 铁、金、钻石等箱子升级配方 ID 现在可以正确解析并递归合成。
3. Wizards Reborn 的 KubeJS/动态配方会根据实际配方类型路由到奥术工作台等正确机器，不再仅依赖容易误判的配方 ID。
4. Malum 精魂坩埚与精魂祭坛会刷新周围加速结构状态，使精魂催化器和符文木方尖碑的加成正常生效。
5. Goety 仪式会在抽取材料前验证祭坛条件；绑定多个祭坛时会尝试满足条件的候选机器，并可在配方计划中手动选择机器。
6. Botania 符文祭坛会自动执行森林法杖点击，完善批量制作、取消回收和产物收集，避免产物残留或掉落地面。
7. 改进 Botania 魔力池的绑定判断、机器路由和产物处理。
8. 修复 Iron Furnaces、原版熔炉类机器及若干物理工作台的错误分派。
9. 同时兼容 Youkai's Homecoming 与 Gensokyo Delight（`youkaisfeasts`），覆盖蒸笼、发酵缸、水壶、料理台和三种尺寸的锅；Moka 仍仅属于 Youkai's Homecoming。

## 配方树、JEI 与机器管理

1. 配方树会保留同一产物的替代配方，允许在多个制作路线之间切换。
2. 为 Goety 祭坛和其他存在多个绑定实例的物理机器增加候选机器展示与选择。
3. 改进 JEI 框选配方、动态配方 ID、CraftTweaker/KubeJS 生成配方及 grouped 配方的解析。
4. 优化大型压缩链和 Prefab 配方的规划：优先消耗库存、合并相同需求，并避开木箱变体和解压循环导致的超时。
5. 机器管理中心新增 `Ctrl + 左键` 快速取消绑定，操作后列表会立即同步刷新。
6. 修复重新进入世界后机器管理中心入口因绑定状态未恢复而暂时消失的问题。
7. 阻止共振磁盘被 `Shift + 右键` 意外拆解成 4K 存储部件和元件外壳。

## 稳定性与诊断

1. 可选模组缺失、版本变化或反射接口不兼容时改为安全跳过，避免整合包启动或运行时直接崩溃。
2. 修复配方图验证、自定义 Ingredient 匹配和动态卷轴输出处理中出现的多处崩溃。
3. 降低正常动态配方造成的重复警告和日志污染，同时保留真正异常配方类型的警告。
4. 新增和扩充递归规划、材料回收、机器路由、法术卷轴、Botania、Malum、Sophisticated Storage、Youkai/Gensokyo 与酿造系统的回归测试。

## 升级说明

- 网络协议从 `30` 升级到 `31`，客户端和服务端必须同时安装 RS Integration `1.3.3`，旧版本会在连接时被拒绝。
- 服务端配置结构版本未变化，无需删除或重建配置文件。
- 更新不会清除现有 RS 网络、机器绑定或已有存储内容。
- 建议整合包作者同时更新服务端与客户端模组文件，避免协议版本不一致。
