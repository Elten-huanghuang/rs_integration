# 递归合成界面

主界面分为固定标题、材料摘要、工具栏、树画布/材料整页和底部操作栏。右侧抽屉与工具栏上沿对齐，包含步骤、缺料、条件三个页签。小 GUI 下抽屉向上延伸，给候选卡片和条件列表保留滚动空间。原独立步骤卡片/网格视图移除，JEI 的真实配方格子预览保留；监控器不使用本布局。

默认主题沿用展示图的墨绿背景、低对比边框、浅绿选中状态和琥珀色缺料卡片。步骤节点显示名称、数量及机器，原材料默认使用紧凑物品槽。底色及圆角全部使用原版 `GuiGraphics` 批次绘制，避免即时三角扇在整合包中消失。

## 功能对应

| 功能 | 新界面入口 | 行为与检查 |
| --- | --- | --- |
| 查看材料变体 | 步骤 → 材料种类独立子页 | 搜索、自动选材、具体变体、返回详情；同一配方与同类候选需求共用材料锁 |
| 切换制作配方 | 步骤 → 切换配方独立子页 | 同物品及 NBT 共用选择；候选内保留 JEI 布局，支持搜索、方向键与 Enter |
| 禁用/恢复候选 | 右键配方卡片 | 根目标不能禁用；中间需求可仅用库存或恢复递归制作 |
| 忘记默认配方 | 配方区底部 | 清除该材料的持久配方偏好，再向服务端检查路线 |
| 查看当前步骤配方 | 点击步骤后，详情卡片下方直接展示 | 当前 JEI 配方显示单次用料；上方仍显示本计划需求与补做数量；切换候选使用独立按钮 |
| 总材料及余产物 | 全宽材料表、顶部固定摘要 | 共用服务端材料账单；摘要按宽度分页，固定显示需求/库存；材料表支持搜索、仅看缺料、定位与收藏 |
| 缺料 | 标题“缺少 N 种材料”提示或抽屉第二页签 | 点击数量提示直接展开缺料列表；卡片显示需求、库存和净缺口，支持定位、收藏、全部收藏和跳转完整材料表 |
| 前置条件与使用提示 | 标题“N 条条件提示”或抽屉第三页签 | 点击数量提示直接展开条件列表；完整换行显示，支持重新检查；保留研究、机器、并行及服务端诊断；条件不会混成物品缺料 |
| 切换失败 | 步骤页提示 → 查看原因 | 保留之前的树与可用选择，显示失败原因；失败不保存选材/配方/禁用草稿 |
| 步骤导航 | 工具栏“步骤导航” | 搜索、列表定位、上/下一步骤；展开祖先并定位，仅查看，不请求重算 |
| 机器选择 | 工具栏“机器” | 自动/优先/独占、候选状态与坐标、打开目标机器；连接原执行参数 |
| 树的阅读与操作 | 左侧画布、右下真实缩略导航 | 名称、数量、选中边框、折叠、平移、Ctrl+滚轮缩放、中键打开 JEI；适配整树和缩略导航只调整相机 |
| 数量与执行策略 | 底部固定操作栏 | 次数输入、±1、+10、+64；下拉保留全部八个快捷项；严格/只准备材料、产物去向与具体存储网络选择 |
| 余烬专属信息 | 工具栏“余烬”独立滚动页 | 基座布局、种子、计算/反推开关保留；按实际宽度计算卡片行数 |

节点数量仍遵守原有显示上限；被显示上限隐藏的步骤，其服务端条件仍出现在问题页。仅查看侧栏、搜索与相机操作不会触发路线规划。更改材料或配方才沿用原服务端预览入口。库存更新只刷新材料状态，不重建树。

顶部搜索在树页输入后展示结果下拉框，支持名称、物品 ID 和拼音，也能查找折叠的节点。结果显示图标、数量、上级材料与位置编号，同名节点可分别选择；鼠标点选或方向键加回车确认，Esc 收起，结果过多可滚动。选中后展开祖先、居中并放大到便于阅读的比例（通常 150%，小画布按卡片可容纳尺寸调整，已有更大比例时保留）。输入本身不移动树；材料页仍即时筛选清单。条件列表点击只定位相应节点，保留当前页签、搜索和滚动位置。只有“重新检查路线”会主动重新运算；标题区显示计算阶段、耗时、完成或失败信息。重算期间保留上次树，失败后可重新检查或修改选择。

步骤详情只绑定轻量选择状态并展示当前步骤的配方，进入“切换配方”子页时才加载其他候选的 JEI 预览；同次建树中相同配方的材料候选提取复用一次。库存变动不会重建条件、步骤和机器列表。

背景点阵、连线、节点纯色底图与面板圆角使用托管批次绘制，减少逐个图形提交；物品仍使用原生绘制。屏幕外节点和分支连线不提交绘制。缩略导航在布局或尺寸改变时缓存整树投影，合并重复的同色像素；平移、缩放和切换选中节点时复用投影，仅更新视野框与高亮。条件列表在数据或可用宽度改变时缓存换行和行高，每帧只遍历可见行。

GUI 3× 常见的 640×336 逻辑尺寸也纳入绘制检查。紧凑摘要的余产物图标缩至 12 像素，与数量、翻页按钮和点击区域一起限制在摘要内；合成/取消按钮的实际高度与布局一致。缩略导航绘制于主树物品层之上，避免物品穿过导航背景。

## 调色与尺寸

首次运行生成 `config/rs_integration/plan_ui.toml`，这是本机 CLIENT 配置。与监控器的主题配置独立。可参考 [展示图主题示例](plan-ui.example.toml)。更新模组不会强制覆盖玩家已有配色，使用旧配置时需要自行调整对应项目。

`colors` 包含画布、侧栏、卡片、边框、强调色、文字、缺料、条件、树连线与引用角标等颜色。物品贴图、JEI 自带配方纹理及模组提供的提示保留其自身绘制。支持 `#RRGGBB`、`#AARRGGBB`，无效值由 Forge 校验恢复默认。

`layout.panelWidth` 为期望宽度，屏幕较窄时自动缩小，为树保留空间；`listRowHeight` 控制普通列表行高，宽屏缺料卡片保留较大高度；`connectorWidth` 控制连线粗细。关闭 `showNodeNames` 可恢复紧凑图标节点，打开 `showLeafNames` 可给原材料也显示名称，`nodeLabelWidth` 可调整名称区宽度。配置加载或重载后，重新打开界面可查看完整布局变化。

`minimapWidth`、`minimapHeight` 控制右下缩略导航的期望尺寸，默认 160×100 GUI 像素；实际大小会限制在画布宽高的三分之一以内。

## 验证边界

相关自动检查覆盖材料选择与回滚、节点恢复、真实侧栏绘制与点击命中、JEI 预览调用、库存刷新、隐藏步骤条件、小窗口滚动、机器选择、配方候选键盘操作、颜色解析和配置重载。测试替换了 OpenGL、字体/物品渲染等运行环境，不等同于游戏内截图验收。

`PlanWorkspaceRenderTest` 执行生产 Screen 和组件的真实渲染方法，将命令导出至 `build/plan-ui-render/`；使用 `src/test/resources/plan-ui/render_preview.py` 可回放成 PNG。回放保留生产坐标、颜色、缩放和嵌套裁剪，包含总览、缺料、条件、步骤、配方、材料整页、变体和次数菜单，以及 960×540、427×240 GUI 尺寸。字体与物品图使用替代环境，JEI 内部区域明确标注占位，因此回放不能当作游戏截图。

游戏内仍需核对整合包的 GUI 缩放、资源包字体、第三方 JEI 类别实际绘制、模组长提示以及机器远程界面的打开结果。没有运行中的游戏客户端时，不能以单元测试声称已经验证这些画面。
